# テクスチャ

天然素材、繊維、摩耗、その他の素材の特徴など、表面の特徴に焦点を当てます。

#### 石と鉱物

石や鉱物の表面を、葉脈、粒子、地層、劈開、結晶、斑点、半透明性、研磨または風化した構造によって比較します。

細かく比較的滑らかな石の母材の中を、曲がりくねった鉱脈が通っています。

<a id="form-exp-13-0-1"></a>

![花崗岩の粒子 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-1.svg)

##### 砂岩の地層

細粒と堆積した色層から平行または湾曲した堆積帯を形成します。

![スレート レイヤー — ビジュアル スタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-3.svg)

##### スレート層

薄い平面の亀裂と連続した層の分離によって表面を作成します。

![石灰岩の細孔 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-4.svg)

##### 石灰岩の細孔

石灰岩の表面には、細かい孔、浅い溝、不均一な堆積物が組み合わされています。

![小石モザイク — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-5.svg)

<a id="form-exp-13-0-6"></a>

![結晶クラスター — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-6.svg)

##### 水晶クラスター

多くのファセットクリスタルをクラスター化して、鋭い点と反射のリズムを作り出します。

<a id="form-exp-13-0-7"></a>

![瑪瑙のバンド — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-7.svg)

##### 瑪瑙バンド

内側をミネラルカラーの連続した曲線バンドで包みます。

<a id="form-exp-13-0-8"></a>

![岩石の割れ目 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-8.svg)

##### 岩石の割れ目

![褶曲した岩層 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-9.svg)

##### 褶曲した岩層

##### 溶岩の孔

固化した溶岩の表面にさまざまなサイズの細孔と流れの痕跡を保持します。

#### 土と砂

<a id="form-exp-13-1-0"></a>

![細かい砂 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-0.svg)

##### 細かい砂

小さな粒子と微妙な浅い凹凸で均一な表面を作成します。

<a id="form-exp-13-1-1"></a>

![砂の波紋 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-1.svg)

##### 砂の波紋

細かい波状のうねを風によって形成される方向に揃えます。

<a id="form-exp-13-1-2"></a>

![土壌粒子 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-2.svg)

##### 顆粒土

開いた気孔を持つさまざまなサイズの土の塊を混合して、緩い構造を作成します。

<a id="form-exp-13-1-3"></a>

![ひび割れた泥 – 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-3.svg)

##### ひび割れた泥

表面を枝分かれした収縮亀裂を持つ不規則な多角形に分割します。

<a id="form-exp-13-1-4"></a>

![塩の結晶 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-4.svg)

##### 塩の結晶

地面を青白い結晶と脆い塩の地殻で覆います。

<a id="form-exp-13-1-5"></a>

![混合砂利 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-5.svg)

##### 混合砂利

<a id="form-exp-13-1-6"></a>

![風によって侵食された溝 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-6.svg)

##### 風によって侵食された溝

<a id="form-exp-13-1-7"></a>

![水で侵食された水路 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-7.svg)

##### 水で侵食された水路

水が地表を横切った場所に、分岐または平行な浸食溝を残します。

<a id="form-exp-13-1-8"></a>

![苔カバー — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-8.svg)

多くの小さなコケ植物から柔らかく緻密な粒状層を構築します。

<a id="form-exp-13-1-9"></a>

![苔癬斑点 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-9.svg)

##### 苔癬斑

さまざまな色の薄い斑点を石や樹皮の表面に貼り付けます。

![火山灰 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-10.svg)

##### 火山灰

細かい粉末、破片、およびわずかな表面のクラストから灰色の層を形成します。

![凍った地面の亀裂 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-11.svg)

凍結と収縮の痕跡から網目のような地模様を作成します。

#### 水の氷と空気の痕跡

流れのパターン、液滴の形状、凝縮、泡、霜、割れ目、霧、および浮遊運動によって、水、氷、および空中の痕跡を比較します。

<a id="form-exp-13-2-0"></a>

![細かい水の波紋 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-2-0.svg)

##### 細かい水の波紋

反射をわずかに曲げるには、細かい水の波紋を使用します。

<a id="form-exp-13-2-1"></a>

![同心円状の波紋 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-2-1.svg)

##### 同心円状の波紋

1 つまたは複数の点から外側に向かって円形の波紋を広げます。

<a id="form-exp-13-2-2"></a>

![交差する波紋 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-2-2.svg)

##### 交差する波紋

さまざまな方向に広がる波紋が交差し、網目のようなリズムを生み出します。

<a id="form-exp-13-2-3"></a>

![乱流渦 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-2-3.svg)

##### 乱流渦

カールする流線と渦を組み合わせて、複雑な乱流の水面を作ります。

<a id="form-exp-13-2-4"></a>

![泡のテクスチャー - 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-2-4.svg)

##### 泡の質感

高密度の泡、薄いフィルム、壊れた泡状のエッジから表面を構築します。

<a id="form-exp-13-2-5"></a>

![雨の跡 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-2-5.svg)

##### 雨の跡

さまざまな大きさの雨粒を、その跡とともに散らばらせます。

<a id="form-exp-13-2-6"></a>

![結露液滴 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-2-6.svg)

##### 結露水滴

小さな水のビーズを冷たい表面に付着させ、いくつかを融合させて大きな水滴にします。

<a id="form-exp-13-2-7"></a>

![氷の亀裂 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-2-7.svg)

##### 氷の亀裂

透明または半透明の氷に細かい亀裂を入れます。

<a id="form-exp-13-2-8"></a>

![フロストクリスタル — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-2-8.svg)

<a id="form-exp-13-2-9"></a>

![雪の粒 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-2-9.svg)

##### 雪の粒

緩やかな雪の粒子と小さな影を使用して、細かいテクスチャーの表面を作成します。

![霧のかかった穀物畑 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-2-10.svg)

AIの指示

## この方向性を AI に取り入れましょう

画像と一緒に使うか、画像生成用のプロンプトをこの表現に合わせて書き直すようAIに依頼してください。

**目指す表現**

テクスチャ

**入力と出力**

画像が与えられた場合は、その画像をこの表現に合わせて調整してください。プロンプトが与えられた場合は、画像生成にそのまま使える完全なプロンプトに書き直してください。

**目指す構成**

関連するパレット、マテリアル、雰囲気を表面主導のアートワークに変換します。完全なカバレッジ、ローカルのフラグメントまたはレイヤーを使用して、独立した焦点の対象となる無関係なオブジェクトを減らします。

**背景**

参照マテリアル、パレット、雰囲気。欠落している場合に関連する表面処理を作成します。ローカル パッチには別のバッキングを含めることができます。全領域のテクスチャが地面とマージされます。支配的なオブジェクトや物語の設定を追加することは避けてください。

**文字の扱い**

元画像ではっきり読める文字とその言語を維持し、見せ方を調整してください。読めない文字を復元できたと主張しないでください。文字が指定されていない場合は、主なモチーフ、動き、構成を隠さない短い関連フレーズを補助的に加えてください。既存の文字は目指す視覚的な優先順位に合わせ、文字を入れないという明示的な指定には従ってください。

**維持と調整**

オブジェクトのシルエットや完全なシーンを必要とせずに、関連するマテリアル、サーフェス、パレット、雰囲気を保持します。マテリアルの手がかりが存在しないときに、ソースの実際のマテリアルを識別したと主張せずに、要求されたエフェクトを作成します。新しく作成されたコンテンツをソースに存在するものとして記述しないでください。明示的な入力制限と必要なターゲット条件の両方が満たされたと主張するのではなく、それらの間の矛盾を述べます。

**適用範囲と制約**

オブジェクトのシルエットまたは環境全体が、代わりに主役またはシーンのアートワークになる場合があります。明確なオブジェクトのないすべての画像がテクスチャであるわけではありません。

コードによる研究では、構成と視覚的処理を比較します。メディアとスタイルの例は概念的なものです。これらの方向は、画像モデルを使用して個別にテストされていません。生成されたテキスト、透明度、リピートエッジを確認します。
