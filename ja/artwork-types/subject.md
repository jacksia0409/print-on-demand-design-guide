# 主役を中心にした構成

何を描いたか分かる物体、その集まり、文字を主役にするデザインです。構図、補助的な装飾、文字との関係を探りましょう。

<a id="subject-design"></a>

## モチーフの構図と表現

<a id="transformation"></a>

ビジュアルフォーム · 144

### モチーフのアート表現

<a id="transformation-panel-word-g22"></a>

<a id="transformation-group-word-g22"></a>

#### 輪郭と線

基礎となる被写体を認識可能なままにして、輪郭がどのように抽出、最小化、または落書きに緩和されるかを比較してください。

<a id="form-art-22-0"></a>

![輪郭抽出 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-22-0.svg)

##### 輪郭抽出

被写体の外側のエッジを決定的な線に分離し、認識可能な輪郭を維持しながら表面のディテールを除去します。

<a id="form-art-22-2"></a>

![最小限の線画 — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-22-2.svg)

##### 最小限の線画

少ないストロークで主役を描写し、フォームの大部分を表示するための空きスペースを残します。

<a id="form-art-22-7"></a>

![走り書きの線 — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-22-7.svg)

##### 落書き線

不規則な動きが被写体に神経質なエネルギーを与える、落ち着きのない重なり合うマークからイメージを構築します。

<a id="transformation-panel-word-g23"></a>

<a id="transformation-group-word-g23"></a>

#### 削減と簡素化

省略、シルエット、アイコン、シンボル、単純化した明暗構造など、そのものらしさを保ちながら細部を減らす方法を比べます。

<a id="form-art-23-0"></a>

![背景を削除する — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-23-0.svg)

##### 背景を削除する

周囲の設定を消去して、被写体がきれいな自己完結型のグラフィック形状として読み取れるようにします。

<a id="form-art-23-1"></a>

![細かい部分を削除する — 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-23-1.svg)

##### 細かい部分を削除する

小さなテクスチャや二次的な部分を抑制し、重要な構造をすぐに読み取れるようにします。

<a id="form-art-23-2"></a>

![識別特徴を保持する — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-23-2.svg)

##### そのものと分かる特徴を残す

被写体を紛れもなくそのものにするいくつかのプロポーション、マーキング、アクセサリーを保存します。

<a id="form-art-23-3"></a>

![選択的省略 - 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-23-3.svg)

##### 選択的省略

選択した領域を意図的に未解決のままにして、完全なレンダリングではなく、制御されたギャップを通して注意を向けます。

<a id="form-art-23-4"></a>

![ネガティブスペースの補完 — 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-23-4.svg)

##### ネガティブスペース補完

空白の領域はエッジが欠けていることを暗示し、見る人は完全には描かれない形を頭の中で完成させます。

<a id="form-art-23-5"></a>

![シルエットへの簡略化 — 表現例](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-23-5.svg)

##### シルエットへの簡略化

主役をベタ塗りのシルエットに単純化し、ポーズと外形だけで何か分かるようにします。

<a id="form-art-23-6"></a>

![アイコン化による簡略化 — 表現例](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-23-6.svg)

##### アイコン化による簡略化

主役を、はっきりした幾何学形を持ち、小さくても一目で分かるコンパクトなピクトグラムに簡略化します。

<a id="form-art-23-7"></a>

![シンボルへの単純化 — 表現例](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-23-7.svg)

##### シンボルへの単純化

アイデアを象徴的な記号に変換し、文字通りの外観よりも概念的な認識を優先します。

<a id="form-art-23-8"></a>

![カラーブロックの単純化 — 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-23-8.svg)

##### カラーブロックの簡略化

段階的なモデリングを、フラットな色のいくつかの幅広で連動した領域に置き換えます。

<a id="form-art-23-9"></a>

![明暗のグループ化 — 表現例](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-23-9.svg)

##### 明暗のグループ化

連続的なシェーディングではなく、明暗を少数の明確な色調の塊に整理します。

<a id="form-art-23-10"></a>

![単純化された輪郭 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-23-10.svg)

##### 簡略化された輪郭

不揃いな縁を滑らかで簡潔な輪郭に整え、主役を特徴づけるシルエットを保ちます。

<a id="form-art-23-11"></a>

![簡略化された内部構造 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-23-11.svg)

##### 簡略化された内部構造

主要な内部分割のみを保持し、小さな解剖学的構造、テクスチャ、下書き線を削除します。

<a id="transformation-panel-word-g24"></a>

<a id="transformation-group-word-g24"></a>

#### プロポーションと形状

認識可能な形状のプロポーション、体積、曲率、圧縮、ねじれ、レンズのような変形に対する意図的な変更を比較します。

<a id="form-art-24-0"></a>

![特大の頭 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-24-0.svg)

##### 特大ヘッド

自然なプロポーションをはるかに超えて頭を拡大し、表情、無邪気さ、またはコミカルな性格を強調します。

<a id="form-art-24-1"></a>

![細長い体 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-24-1.svg)

##### 細長い体

胴体と全体のシルエットを縦に伸ばし、エレガントな、あるいは意図的に不気味な体型を演出します。

<a id="form-art-24-2"></a>

![短くなった手足 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-24-2.svg)

##### 手足が短くなった

腕や脚を圧縮してずんぐりとしたプロポーションにし、体をコンパクトで遊び心を感じさせます。

<a id="form-art-24-3"></a>

![拡大された体の詳細 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-24-3.svg)

##### 拡大されたボディの詳細

1 つの解剖学的特徴を拡大して、それがキャラクターの主要な視覚的手がかりとなるようにします。

<a id="form-art-24-4"></a>

![ボディの詳細を削減 — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-24-4.svg)

##### ボディのディテールを縮小

選択したフィーチャを縮小して、コントラスト、脆弱性、または意図的に奇妙な比率を作成します。

<a id="form-art-24-5"></a>

![丸みを帯びたフォルム — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-24-5.svg)

##### 丸みを帯びたフォルム

角や接合部を柔らかくしてふっくらとした曲線にし、どの塊もクッション性のある優しい印象を与えます。

<a id="form-art-24-6"></a>

![細いフォーム — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-24-6.svg)

##### スリムなフォルム

細めの幅とテーパードフォルムで、無駄のない繊細な上向きのシルエットを実現。

<a id="form-art-24-7"></a>

![平坦化されたフォーム — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-24-7.svg)

##### フラット化されたフォーム

ボリュームが前面が広く、押し込まれた浅い形状になるまで深さを圧縮します。

<a id="form-art-24-8"></a>

![膨らんだフォーム — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-24-8.svg)

##### 膨張したフォーム

空気をはらむように外側に向かってボリュームを広げ、エッジを丸めながらシルエットを引き締めます。

<a id="form-art-24-9"></a>

![押しつぶされたフォーム — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-24-9.svg)

##### 潰れたフォーム

フォームを下または横に押して、ずんぐりとしたプロポーションと目に見える圧縮を作り出します。

<a id="form-art-24-10"></a>

![曲がったフォーム — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-24-10.svg)

##### 曲がったフォーム

通常は硬いパーツを明確な関節で湾曲させ、姿勢、張力、またはアニメーションのような弾力性を導入します。

<a id="form-art-24-11"></a>

![ねじれた形 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-24-11.svg)

##### ねじれたフォルム

接続されたパーツを反対方向に回転させると、フォームが歪んだりねじれ応力が加わったように見えます。

<a id="form-art-24-12"></a>

![波状変形 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-24-12.svg)

##### 波状変形

輪郭全体を滑らかな交互曲線でうねらせ、直線的な構造を流れるような動きに置き換えます。

<a id="form-art-24-13"></a>

![誇張された遠近感 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-24-13.svg)

##### 誇張された視点

近くの形状を劇的に大きくし、遠くの形状を小さくして空間の奥行きを強調します。

<a id="form-art-24-14"></a>

![魚眼歪み — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-24-14.svg)

##### 魚眼歪み

丸い視野の周囲で直線を湾曲させ、広角レンズのような膨らみを作ります。

<a id="transformation-panel-word-g25"></a>

<a id="transformation-group-word-g25"></a>

#### キャラクターの個性づけ

擬人化、表情、手足、服、職業、性格、英雄性、怪物性、機械への生命感を通じて、モチーフをキャラクターにする方法を比べます。

<a id="form-art-25-0"></a>

![擬人化された動物 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-25-0.svg)

##### 擬人化された動物

種の特徴を保ちながら、動物に人間の姿勢、身振り、服装、または社会的行動を与えます。

<a id="form-art-25-1"></a>

![擬人化されたオブジェクト — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-25-1.svg)

##### 擬人化されたオブジェクト

日用品の元の構造を生かした顔や身振りを加え、命を吹き込むように擬人化します。

<a id="form-art-25-2"></a>

![擬人化された食べ物 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-25-2.svg)

##### 擬人化された食べ物

おいしそうで何の食べ物か分かる形を保ちながら、表情豊かな特徴を加え、食べ物をキャラクターに変えます。

<a id="form-art-25-3"></a>

![擬人化された植物 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-25-3.svg)

##### 擬人化された植物

茎、葉、花を人間の感情と目的のある動きを持った生命体として使用します。

<a id="form-art-25-4"></a>

![表現の追加 — ビジュアル スタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-25-4.svg)

##### 追加された表現

最小限の目、口、眉を加えて、選んだ感情がはっきり伝わる表情にします。

<a id="form-art-25-5"></a>

![手足の追加 - 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-25-5.svg)

##### 追加された手足

腕や脚を取り付けて、人間以外の被写体がキャラクターのようにポーズ、動作、対話できるようにします。

<a id="form-art-25-6"></a>

![服を着たキャラクター — ビジュアル スタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-25-6.svg)

##### 服を着たキャラクター

衣服を使用して、役割、時代、地位、気質を示唆しつつ、根底にある人物像を読み取れるようにします。

<a id="form-art-25-7"></a>

![職業を持つキャラクター — 表現例](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-25-7.svg)

##### 職業を持つキャラクター

職業特有の服装、道具、姿勢、仕事ぶりを通じてキャラクターを定義します。

<a id="form-art-25-8"></a>

![性格キャラクター — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-25-8.svg)

##### 個性的なキャラクター

姿勢、表情、スタイリング、そして繰り返される行動の詳細を通じて、一貫した気質を構築します。

<a id="form-art-25-9"></a>

![英雄的なキャラクター — ビジュアル スタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-25-9.svg)

##### 英雄的なキャラクター

スタンスを広げ、視線を鋭くし、上向きのジェスチャーを使用して勇気と決意を伝えます。

<a id="form-art-25-10"></a>

![モンスター キャラクター — ビジュアル スタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-25-10.svg)

##### モンスターキャラクター

解剖学を脅迫的または奇妙な形に歪め、恐怖と記憶に残るキャラクターのロジックのバランスをとります。

<a id="form-art-25-11"></a>

![機械生命体 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-25-11.svg)

##### 機械生命体

機械と意識の兆候を組み合わせて、関節、センサー、鎧を生きた解剖学のように感じさせます。

<a id="transformation-panel-word-g26"></a>

<a id="transformation-group-word-g26"></a>

#### 分解と組み立て

アセンブリ ロジックが可視化されたままで、サブジェクトがどのように分割、移動、ミラー化、モジュール化、再構築されるかを比較します。

<a id="form-art-26-0"></a>

![幾何学的な分解 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-26-0.svg)

##### 幾何学的分解

被写体を基本的なポリゴンまたはソリッドに分割し、基礎となる構築されたジオメトリを明らかにします。

<a id="form-art-26-1"></a>

![レイヤードスライス - 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-26-1.svg)

##### 層状スライス

フォームを平行な断面に分割し、それらをわずかに分離して層状のボリュームを露出させます。

<a id="form-art-26-2"></a>

![再構築された断片 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-26-2.svg)

##### 再構築された断片

継ぎ目が目に見えてアクティブなままである、移動した破片から認識可能な全体を再構築します。

<a id="form-art-26-3"></a>

![結合された平面 — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-26-3.svg)

##### 結合された平面

角張ったサーフェスを端から端まで接続し、滑らかなモデリングではなく平面ファセットでボリュームを定義します。

<a id="form-art-26-4"></a>

![局所的な変位 - 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-26-4.svg)

##### 局所的な変位

被写体の残りの部分は安定させたまま、1 つの領域を元の位置からずらします。

<a id="form-art-26-5"></a>

![複数のビューのアセンブリ — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-26-5.svg)

##### マルチビューアセンブリ

単一の視点に従うのではなく、正面、側面、上面の観察を 1 つの図に結合します。

<a id="form-art-26-6"></a>

![繰り返しのオーバーレイ — 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-26-6.svg)

##### 繰り返しのオーバーレイ

半透明またはオフセットしたコピーを積み重ねると、輪郭が蓄積されて奥行きと視覚的な振動が生まれます。

AIで広げる創作の方向性

## この方向性を AI に取り入れましょう

画像と一緒に使うか、画像生成用のプロンプトをこの表現に合わせて書き直すようAIに依頼してください。

**目指す表現**

主役を中心にした構成

**入力と出力**

画像が与えられた場合は、その画像をこの表現に合わせて調整してください。プロンプトが与えられた場合は、画像生成にそのまま使える完全なプロンプトに書き直してください。

**目指す構成**

主要なオブジェクトや文言を選択し、読みやすい階層を確立します。 1 つの主役、複数の主役、またはテキストと画像の関係を使用し、中心となるコンテンツを背景でサポートします。

**背景**

既存の背景の内容、表現方法、配色を参考にし、目指す構成に合わせて調整してください。背景がない場合、または単なる無地や透明の場合は、テーマに合った背景表現を作成してください。単色、透明、その他の背景について明示的な指定があれば、その指定を優先してください。

**文字の扱い**

元画像ではっきり読める文字とその言語を維持し、見せ方を調整してください。読めない文字を復元できたと主張しないでください。文字が指定されていない場合は、主なモチーフ、動き、構成を隠さない短い関連フレーズを補助的に加えてください。既存の文字は目指す視覚的な優先順位に合わせ、文字を入れないという明示的な指定には従ってください。

**維持と調整**

中心となるテーマと、元の対象を識別できる特徴を維持してください。元の表現方法と配色を出発点とし、選んだ表現に必要な範囲だけ変更してください。新たに作成した内容を、元画像に存在していたものとして説明しないでください。明示的な入力条件と、目指す結果に必要な条件が矛盾する場合は、両方を満たしたと主張せず、その矛盾を説明してください。

**適用範囲と制約**

特定可能な中心的な主役を、環境、装飾的な繰り返し、物質的な表面、または非具象的な抽象化に置き換えないでください。

コードで描いた図で、構図や視覚表現を比較します。画材やスタイルの例は概念を示すもので、これらの方向性を画像モデルで一つずつ検証したものではありません。生成した文字、透過、リピートの継ぎ目を確認してください。
