# 抽象表現

特定の物体を表さず、形、描き跡、線、色の関係を主役にします。

<a id="abstract-design"></a>

#### 点と線

抽象的な点と線のシステムを、分離、クラスタリング、方向、連続性、フィールド密度、収束、カリグラフィー エネルギーによって比較します。

##### 孤立したドット

位置によって関係が確立されるいくつかの別々のドットから構成を作成します。

<a id="form-exp-12-0-1"></a>

![クラスター化されたドット — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-1.svg)

##### クラスター化されたドット

ドットの集合と分散を使用して、視覚的に強調する領域を確立します。

<a id="form-exp-12-0-2"></a>

![ドットフィールド — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-2.svg)

連続フィールドとして読み取られるまで、一定の間隔でドットを配置します。

<a id="form-exp-12-0-3"></a>

![粒子雲 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-3.svg)

##### 粒子雲

多数の小さなドットから雲のような濃度の変化を構築します。

<a id="form-exp-12-0-4"></a>

![平行線 - 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-4.svg)

##### 平行線

平行な直線の間隔や長さを変えることで、リズムを生み出します。

<a id="form-exp-12-0-5"></a>

![クロスラインウェブ — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-5.svg)

##### クロスラインウェブ

いくつかの直線を交差させて、目に見える非具象的な構造を形成します。

<a id="form-exp-12-0-6"></a>

![ジグザグ — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-6.svg)

##### ジグザグ

鋭く回転する線分を使用して角度のリズムを作成します。

<a id="form-exp-12-0-7"></a>

![円弧 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-7.svg)

##### 円弧

AIで広げる創作の方向性

## この方向性を AI に取り入れましょう

画像と一緒に使うか、画像生成用のプロンプトをこの表現に合わせて書き直すようAIに依頼してください。

**目指す表現**

抽象表現

**入力と出力**

画像が与えられた場合は、その画像をこの表現に合わせて調整してください。プロンプトが与えられた場合は、画像生成にそのまま使える完全なプロンプトに書き直してください。

**目指す構成**

パレット、リズム、方向性、または気分を幾何学的な形、有機的な流れ、マーク、またはカラーフィールドに変換します。具体的なオブジェクトを保存することを主な目標とするのではなく、関係性と空間を再編成します。

**背景**

元の背景の配色、リズム、雰囲気を参考にします。なければ、関連する下地や空間関係を作ります。具象的な元画像の周囲は、非具象の構図を置き換えず、補助的な手がかりへ簡略化できます。

**文字の扱い**

元画像ではっきり読める文字とその言語を維持し、見せ方を調整してください。読めない文字を復元できたと主張しないでください。文字が指定されていない場合は、主なモチーフ、動き、構成を隠さない短い関連フレーズを補助的に加えてください。既存の文字は目指す視覚的な優先順位に合わせ、文字を入れないという明示的な指定には従ってください。

**維持と調整**

具体的な物体の識別性を弱めたり取り除いたりしても、テーマ、雰囲気、配色、リズム、方向性を保ちます。元の物体のシルエットも同時にそのまま残すよう要求しないでください。新しく作った内容を元画像にあったものと説明しないでください。明示的な入力条件と、目指す結果に必要な条件が矛盾する場合は、両方を満たしたとせず、その矛盾を示してください。

**適用範囲と制約**

様式化しても何を描いたか分かる物体は、モチーフを描く表現に含まれます。素材の表面の質感が主な表現なら、肌理の分類に入ります。

コードで描いた図で、構図や視覚表現を比較します。画材やスタイルの例は概念を示すもので、これらの方向性を画像モデルで一つずつ検証したものではありません。生成した文字、透過、リピートの継ぎ目を確認してください。
