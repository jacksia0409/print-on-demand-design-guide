# パターン

モチーフは、繰り返しや明確な配置によって装飾的な全体を作成します。シームレスなリピートには独自のエッジ チェックが必要です。

![花柄リピートパターンのタイルレイアウト例](https://images.podplo.app/official/skills/podplo-skill-media-20261027/skills/podplo-skill-8.webp)

## パターンの構図と表現

<a id="pattern"></a>

ビジュアルフォーム · 66

### パターン要素と構成

<a id="pattern-panel-word-g59-pattern"></a>

<a id="pattern-group-word-g59-pattern"></a>

#### 方向と動作のパス

デザインされたフィールド内で、一方向、交互、回転、放射状、曲線、または一方向の動きにモチーフの方向がどのように従うかを比較します。

<a id="form-pattern-59-0"></a>

![一方向の方向性 — 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-0.svg)

##### 一方通行の方向性

すべてのユニットを同じ方向に向けて、上向き、移動、または成長する動きを強化します。

<a id="form-pattern-59-1"></a>

![双方向の逆転 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-1.svg)

##### 双方向の逆転

直立したユニットと倒立したユニットを交互に配置して、反対の垂直方向のリズムを作り出します。

<a id="form-pattern-59-2"></a>

![4 方向交互 - 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-2.svg)

##### 4方向交互

パターンに単一の主要な読み取り方向がないように、ユニットを 4 つの方向に循環させます。

<a id="form-pattern-59-3"></a>

![多方向回転 - 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-3.svg)

##### 多方向回転

ユニットをさまざまな角度に配置して整然とした列を避け、あらゆる方向からの観察をサポートします。

<a id="form-pattern-59-4"></a>

![接線循環 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-4.svg)

##### 接線循環

魚や木の葉が中心の周りを回るように、各ユニットを円の接線に沿って回転させます。

<a id="form-pattern-59-5"></a>

![内向きの収束 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-5.svg)

##### 内側への収束

ユニットを 1 つの中心に向けたり、外側に反転させたりして、収束または拡大を生み出します。

<a id="pattern-panel-word-g60-pattern"></a>

<a id="pattern-group-word-g60-pattern"></a>

#### モチーフシーケンスとビート

交互、サイクル、メインビートとフィラービート、ペア、クラスター、サイズ変更、混合スケール、均等間隔などを通じてモチーフシーケンスを比較します。

<a id="form-pattern-60-0"></a>

![AB 交代 - 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-0.svg)

##### AB交互

ABAB の順序で 2 つのユニット タイプを交互に配置し、形や色の違いを利用してリズムを確立します。

<a id="form-pattern-60-1"></a>

![ABC サイクル — 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-1.svg)

##### ABCサイクル

3 つ以上のユニット タイプを固定の順序でサイクルして、より長い反復ビートを作成します。

<a id="form-pattern-60-2"></a>

![メインビートとフィラービート — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-2.svg)

##### メインとフィラーのビート

パターンが明確な階層を維持できるように、大きなメイン ユニットと小さなフィラー要素を繰り返します。

<a id="form-pattern-60-3"></a>

![ペアのモチーフ — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-3.svg)

##### ペアモチーフ

まず 2 つの一致するユニットまたは関連するユニットをペアにしてから、孤立した単一の要素の代わりにペアを繰り返します。

<a id="form-pattern-60-4"></a>

![クラスター化されたモチーフ — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-4.svg)

##### クラスター化されたモチーフ

各クラスターを繰り返す前に、小さな要素を花束、果物のクラスター、またはオブジェクト グループに組み立てます。

<a id="form-pattern-60-5"></a>

![交互のサイズ — 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-5.svg)

##### 交互のサイズ

大小のユニットが交互に配置されているため、形状の違いではなくスケールの違いがビートを生み出します。

<a id="form-pattern-60-6"></a>

![混合スケール — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-6.svg)

##### 混合スケール

同じ要素を複数のサイズで組み合わせて奥行きを表現し、視覚的な豊かさを高めます。

<a id="form-pattern-60-7"></a>

![等間隔 - 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-7.svg)

##### 等間隔

一貫した開いた間隔をリズムの一部として扱い、すべてのユニットを明確に独立させます。

<a id="pattern-panel-word-g61-pattern"></a>

<a id="pattern-group-word-g61-pattern"></a>

#### 密度と勾配

モチーフの密度、スケール、方向、色、または周囲の空間の濃度を変更することによって生成された空間勾配を比較します。

<a id="form-pattern-61-0"></a>

![まばらなオープンスペース - 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-0.svg)

##### まばらなオープンスペース

エリア全体に明るく静かなパターンを実現するには、いくつかのユニットの間に十分な隙間を残します。

<a id="form-pattern-61-1"></a>

![緻密なカバレッジ – ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-1.svg)

##### 緻密なカバレッジ

要素を密に詰め込み、局所的な重なりを許可して、地色が二次的なものになるようにします。

<a id="form-pattern-61-2"></a>

![密度勾配 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-2.svg)

##### 密度勾配

単位面積あたりの要素の数を少しずつ変え、疎から密へ、または密から疎へ移行させます。

<a id="form-pattern-61-3"></a>

![スケールの勾配 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-3.svg)

##### スケールグラデーション

ユニットのサイズを一方向に沿って拡大または縮小して、前進、距離、または分散を示唆します。

<a id="form-pattern-61-4"></a>

![方向の勾配 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-4.svg)

##### 方向の勾配

各ユニットの回転を段階的に変更して、回転、ねじり、または流れ場の効果を作成します。

<a id="form-pattern-61-5"></a>

![カラーグラデーション — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-5.svg)

##### カラーグラデーション

レイアウトを安定させたまま、単位ごとの色、明暗、彩度を段階的に変化させます。

<a id="form-pattern-61-6"></a>

![局所濃度コントラスト — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-6.svg)

##### 局所濃度コントラスト

静かなオープンゾーンの横に密集したものを配置して、明確な視覚的重心を作成します。

<a id="pattern-panel-word-g62-pattern"></a>

<a id="pattern-group-word-g62-pattern"></a>

#### 散乱と制御されたランダム性

バランス、ゾーン、クラスター、パス、オーバーラップ、意図的に確保された空きスペースによってランダム性がどのように制限されるかによって、スキャッター システムを比較します。

<a id="form-pattern-62-0"></a>

![バランスの取れた散乱 - 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-0.svg)

##### バランスの取れた散乱

間隔と視覚的な重みを制御しながら、目に見える行を避けて、散布全体のバランスを保ちます。

<a id="form-pattern-62-1"></a>

![制御されたランダム性 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-1.svg)

##### 制御されたランダム性

角度、スケール、最小間隔、要素の比率を制限した後でのみ、配置をランダム化します。

<a id="form-pattern-62-2"></a>

![ゾーン散乱 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-2.svg)

##### ゾーン散乱

読み取り可能なゾーンと自然に柔らかくされたエッジを使用して、さまざまな領域に個別の要素または密度を与えます。

<a id="form-pattern-62-3"></a>

![まとまりごとの散らし配置 — 表現例](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-3.svg)

##### まとまりごとの散らし配置

要素をローカル グループに集めてから、すべてを均等に配置するのではなく、それらのクラスターをフィールド全体に分散させます。

<a id="form-pattern-62-4"></a>

![パスベースの散乱 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-4.svg)

##### パスベースの散乱

目に見えない円弧、波、またはルートに沿って要素を分散させて、フィールドに方向性のある流れを伝えます。

<a id="form-pattern-62-5"></a>

![重なり合う散らし配置 — 表現例](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-5.svg)

##### 重なり合う散乱

オクルージョンを使用して、散在する要素を重ね合わせて奥行きと蓄積感を生み出します。

<a id="form-pattern-62-6"></a>

![確保された空きスペース - 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-6.svg)

##### 確保した余白

要素を文言、主役、選択したシルエットから遠ざけて、スペースを確保してパターンを形成します。

<a id="pattern-panel-word-g68-pattern"></a>

<a id="pattern-group-word-g68-pattern"></a>

#### パターン要素の組み合わせ

認識できるテーマのモチーフがどのように混合され、束ねられ、分散され、リンクされ、または一貫した装飾的な配置に成長するかを比較してください。

<a id="form-pattern-68-0"></a>

![テーマ別オブジェクトの組み合わせ - ビジュアル スタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-0.svg)

##### テーマ別オブジェクトの組み合わせ

パン作りや旅行道具など、1 つのテーマから複数のオブジェクトを組み合わせて、完全なセットを散りばめます。

<a id="form-pattern-68-1"></a>

![散りばめられた花束 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-1.svg)

##### 散りばめられた花束

各花束を繰り返したり散らしたりする前に、花と葉を組み合わせて完全な花束を作ります。

<a id="form-pattern-68-2"></a>

![散在する花の咲く枝 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-2.svg)

##### 散在する花の咲く枝

散らして配置する小枝ごとに、茎、葉、花の自然なつながりを保ちます。

<a id="form-pattern-68-3"></a>

![伸びるつる — 表現例](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-3.svg)

##### 伸びるつる

画面を、枝分かれして曲がるつるの骨組みで満たし、そこに沿って小さな花を添えます。

<a id="form-pattern-68-4"></a>

![風景のビネット — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-4.svg)

##### 風景のビネット

建築、風景、樹木からミニチュア シーンを構築し、さまざまな方向に配布します。

<a id="form-pattern-68-5"></a>

![物語の断片 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-5.svg)

##### 物語の断片

人物、動物、日常の活動などの小さなシーンを繰り返し、各ユニットにミニチュアの物語を持たせます。

<a id="form-pattern-68-6"></a>

![テキストと画像の組み合わせ — 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-6.svg)

##### テキストと画像の混合

単語、文字、数字、図形を組み合わせ、大きさ、方向、間隔でリズムを作ります。

<a id="form-pattern-68-7"></a>

![バッジ グループ — ビジュアル スタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-7.svg)

##### バッジグループ

バッジ、ラベル、シール、または看板を収集可能なステッカー パターンの完全なユニットとして扱います。

<a id="pattern-panel-word-g69-pattern"></a>

<a id="pattern-group-word-g69-pattern"></a>

#### ラインフィールドとドットフィールド

平行線、等高線、ハーフトーン ドット、粒子、雲のようなパッチ、または流体の渦によって形成される連続フィールドを比較します。

<a id="form-pattern-69-0"></a>

![平行線フィールド — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-0.svg)

##### 平行線フィールド

線の幅と固定または変化するギャップをリズムに合わせて使用し、フィールドを多数の平行線で埋めます。

<a id="form-pattern-69-1"></a>

![等高線曲線 — 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-1.svg)

##### 等高線曲線

等高線、年輪、地形線など、複数の曲線を互いにオフセットします。

<a id="form-pattern-69-2"></a>

![ドットハーフトーンフィールド — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-2.svg)

##### ドットハーフトーンフィールド

点の大きさ、密度、配置で、明暗、形、規則的な質感を作ります。

<a id="form-pattern-69-3"></a>

![粒状フィールド — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-3.svg)

##### 粒状フィールド

細かい粒子、短いストローク、または繰り返しが微妙な繊維でフィールドを覆います。

<a id="form-pattern-69-4"></a>

![雲のようなパッチ — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-4.svg)

##### 雲のようなパッチ

不規則なカラー パッチや柔らかい輪郭を曇ったまだらなフィールド全体の表面に合わせます。

<a id="form-pattern-69-5"></a>

![流体の渦 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-5.svg)

##### 流体の渦巻き

流れ場に沿って曲線やカラー バンドを曲げたりカールさせたりして、渦や液体の動きを示唆します。

<a id="pattern-panel-word-g72-pattern"></a>

<a id="pattern-group-word-g72-pattern"></a>

#### 幾何学模様と織物のモチーフ

確立された幾何学モチーフとテキスタイル モチーフを、その単位の形状、方向の繰り返し、織りの関連性、特徴的な視覚的リズムによって比較します。

<a id="form-pattern-72-0"></a>

![水玉模様 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-72-0.svg)

##### 水玉模様

ドットの直径、行の配置、オフセット、間隔を変更して、独特の水玉模様の効果を作成します。

<a id="form-pattern-72-1"></a>

![織りチェック — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-72-1.svg)

##### 織りチェック

縦横の帯を交差させ、幅、組み合わせ、色を変えてチェック柄を作ります。

<a id="form-pattern-72-2"></a>

![千鳥格子 — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-72-2.svg)

##### 千鳥格子

尖った明るいユニットと暗いユニットを千鳥格子の継続的なブロークンチェック効果に連動させます。

<a id="form-pattern-72-3"></a>

![ヘリンボーン — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-72-3.svg)

##### ヘリンボーン

短い対角線のセグメントの方向を交互に変えて、連続的なヘリンボーンのリズムを形成します。

<a id="form-pattern-72-4"></a>

![シェブロン — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-72-4.svg)

##### シェブロン

同じ幅を使用するか、意図的に太さや細さを変化させて、V 字型の線や帯を繰り返します。

<a id="form-pattern-72-5"></a>

![ペイズリー — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-72-5.svg)

##### ペイズリー
