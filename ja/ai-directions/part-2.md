# 公開AI制作指示集

これらはガイドの公開手順であり、プライベート Skill ルールではありません。視覚的な研究は概念的なものです。出力をレビューする必要があります。

## 全領域テクスチャ

表面のディテールが画像全体に表示されるため、メインのコンテンツと地面が 1 つになります。

```text
目指す表現: テクスチャ → 構成 → 全領域テクスチャ

入力と出力: 画像が与えられた場合は、その画像をこの表現に合わせて調整してください。プロンプトが与えられた場合は、画像生成にそのまま使える完全なプロンプトに書き直してください。

目指す構成: 選択したテクスチャを画像全体に拡張します。別の目に見える裏打ち領域を残すことなく、マテリアルのスケール、パレット、密度をエッジ全体で一貫した状態に保ちます。

背景: 関連する色または素材の手がかりを元のバッキングからメインのテクスチャ自体に変換します。バッキングが存在しない場合は、関連する全領域サーフェスの詳細を作成します。コンテンツと地面は、個別の完全な背景が表示されたままになるのではなく、この方向にマージされます。

文字の扱い: 元画像ではっきり読める文字とその言語を維持し、見せ方を調整してください。読めない文字を復元できたと主張しないでください。文字が指定されていない場合は、主なモチーフ、動き、構成を隠さない短い関連フレーズを補助的に加えてください。既存の文字は目指す視覚的な優先順位に合わせ、文字を入れないという明示的な指定には従ってください。

維持と調整: オブジェクトのシルエットや完全なシーンを必要とせずに、関連するマテリアル、サーフェス、パレット、雰囲気を保持します。マテリアルの手がかりが存在しないときに、ソースの実際のマテリアルを識別したと主張せずに、要求されたエフェクトを作成します。新しく作成されたコンテンツをソースに存在するものとして記述しないでください。明示的な入力制限と必要なターゲット条件の両方が満たされたと主張するのではなく、それらの間の矛盾を述べます。

適用範囲と制約: 完全なカバレッジはシームレスなタイリングを意味するものではありません。同時に、不透明な全領域テクスチャの背後に別の完全な背景を視覚的に残す必要はありません。
```


## ローカルテクスチャフラグメント

テクスチャ領域が画像の一部を占め、別の地面が表示されます。

```text
目指す表現: テクスチャ → 構成 → ローカルテクスチャフラグメント

入力と出力: 画像が与えられた場合は、その画像をこの表現に合わせて調整してください。プロンプトが与えられた場合は、画像生成にそのまま使える完全なプロンプトに書き直してください。

目指す構成: 規則的、自然、またはフェード境界を持つ局所的なパッチ内に関連するサーフェスの詳細を集中させます。背景や補足情報を入れるための周囲のスペースを確保してください。

背景: 参照マテリアル、パレット、雰囲気。欠落している場合に関連する表面処理を作成します。ローカル パッチには別のバッキングを含めることができます。全領域のテクスチャが地面とマージされます。支配的なオブジェクトや物語の設定を追加することは避けてください。

文字の扱い: 元画像ではっきり読める文字とその言語を維持し、見せ方を調整してください。読めない文字を復元できたと主張しないでください。文字が指定されていない場合は、主なモチーフ、動き、構成を隠さない短い関連フレーズを補助的に加えてください。既存の文字は目指す視覚的な優先順位に合わせ、文字を入れないという明示的な指定には従ってください。

維持と調整: オブジェクトのシルエットや完全なシーンを必要とせずに、関連するマテリアル、サーフェス、パレット、雰囲気を保持します。マテリアルの手がかりが存在しないときに、ソースの実際のマテリアルを識別したと主張せずに、要求されたエフェクトを作成します。新しく作成されたコンテンツをソースに存在するものとして記述しないでください。明示的な入力制限と必要なターゲット条件の両方が満たされたと主張するのではなく、それらの間の矛盾を述べます。

適用範囲と制約: テクスチャが主なコンテンツのままです。パッチがアイデンティティを支配する識別可能なオブジェクトになった場合は、それを主役のアートワークとして再考してください。
```

## 幾何学的な抽象化

形状、線、比率は、明確なオブジェクト参照なしでデザインを形成します。

```text
目指す表現: 抽象アートワーク → フォーム → 幾何学的な抽象化

入力と出力: 画像が与えられた場合は、その画像をこの表現に合わせて調整してください。プロンプトが与えられた場合は、画像生成にそのまま使える完全なプロンプトに書き直してください。

目指す構成: 入力からパレット、リズム、方向、構造を抽出し、それらを幾何学的な形状や線として再構成します。オブジェクトの認識を維持するのではなく、縮尺、配置、交差点、オープン スペースを使用します。

背景: 背景の色、リズム、雰囲気を参考にしてください。存在しない場合は、関連する支持地面または空間関係を作成します。比喩的なソースの周囲は、非比喩的な構成を置き換えることなく、サポートキューに単純化される場合があります。

文字の扱い: 元画像ではっきり読める文字とその言語を維持し、見せ方を調整してください。読めない文字を復元できたと主張しないでください。文字が指定されていない場合は、主なモチーフ、動き、構成を隠さない短い関連フレーズを補助的に加えてください。既存の文字は目指す視覚的な優先順位に合わせ、文字を入れないという明示的な指定には従ってください。

維持と調整: テーマ、雰囲気、パレット、リズム、または方向性を維持しながら、具体的なオブジェクトのアイデンティティを軽減または削除できます。同時に、元のオブジェクトのシルエットをそのままにする必要はありません。新しく作成されたコンテンツをソースに存在するものとして記述しないでください。明示的な入力制限と必要なターゲット条件の両方が満たされたと主張するのではなく、それらの間の矛盾を述べます。

適用範囲と制約: オブジェクトを依然として明確に描写する幾何学は、幾何学的主役の扱いです。非具象的な幾何学形状は規則的であっても不規則であってもよい。
```

## 無料配布

