# 公開AI制作指示集

これらはガイドの公開手順であり、プライベート Skill ルールではありません。視覚的な研究は概念的なものです。出力をレビューする必要があります。

## 画像またはテクスチャが埋め込まれたタイプ

パターン、画像、または素材の詳細が文字の内側を埋めます。

```text
目指す表現: モチーフ主体 → 文字とモチーフの関係 → 文字の表現 → 画像や質感で埋める文字

入力と出力: 画像が与えられた場合は、その画像をこの表現に合わせて調整してください。プロンプトが与えられた場合は、画像生成にそのまま使える完全なプロンプトに書き直してください。

目指す構成: 関連する画像、パターン、またはテクスチャを文字の境界内に配置します。外側の輪郭を明確に保ち、​​塗りつぶしのスケール、コントラスト、間隔を調整します。

背景: 既存の背景の内容、表現方法、配色を参考にし、目指す構成に合わせて調整してください。背景がない場合、または単なる無地や透明の場合は、テーマに合った背景表現を作成してください。単色、透明、その他の背景について明示的な指定があれば、その指定を優先してください。

文字の扱い: ソースの文言とその言語を明確に読みやすい状態に保ち、その表現を調整します。読めないテキストを回復したと主張しないでください。言葉が指定されていない場合は、テーマに関連した簡潔なコピーを作成し、レタリングをこの処理の焦点にします。読む順序と意味を保持し、スペルをチェックします。明示的なテキストなしのリクエストがこのテキストベースの指示と矛盾する場合は、黙って言葉を追加するのではなく、矛盾していることを述べてください。

維持と調整: 中心となるテーマと、元の対象を識別できる特徴を維持してください。元の表現方法と配色を出発点とし、選んだ表現に必要な範囲だけ変更してください。新たに作成した内容を、元画像に存在していたものとして説明しないでください。明示的な入力条件と、目指す結果に必要な条件が矛盾する場合は、両方を満たしたと主張せず、その矛盾を説明してください。

適用範囲と制約: 塗りつぶしは主に文字を占める必要があります。通常のテキストの後ろに配置された画像は背景であり、レターフォームの塗りつぶしではありません。スペルと読みやすさを再確認してください。
```


## 光線と放射状のアクセント

線または放射状が被写体から外側に伸びます。

```text
目指す表現: モチーフ主体 → 共通の装飾 → 光線と放射状のアクセント

入力と出力: 画像が与えられた場合は、その画像をこの表現に合わせて調整してください。プロンプトが与えられた場合は、画像生成にそのまま使える完全なプロンプトに書き直してください。

目指す構成: 単一の被写体または複数の被写体のグループを維持し、その背後または周囲に局所的な光線または放射状の形状を追加します。焦点となるコンテンツをサポートするために、長さ、密度、リーチを調整します。

背景: 既存の背景の内容、表現方法、配色を参考にし、目指す構成に合わせて調整してください。背景がない場合、または単なる無地や透明の場合は、テーマに合った背景表現を作成してください。単色、透明、その他の背景について明示的な指定があれば、その指定を優先してください。

文字の扱い: 元画像ではっきり読める文字とその言語を維持し、見せ方を調整してください。読めない文字を復元できたと主張しないでください。文字が指定されていない場合は、主なモチーフ、動き、構成を隠さない短い関連フレーズを補助的に加えてください。既存の文字は目指す視覚的な優先順位に合わせ、文字を入れないという明示的な指定には従ってください。

維持と調整: 中心となるテーマと、元の対象を識別できる特徴を維持してください。元の表現方法と配色を出発点とし、選んだ表現に必要な範囲だけ変更してください。新たに作成した内容を、元画像に存在していたものとして説明しないでください。明示的な入力条件と、目指す結果に必要な条件が矛盾する場合は、両方を満たしたと主張せず、その矛盾を説明してください。

適用範囲と制約：実際の発光表現も、完全な輪も必須ではありません。光線は補助装飾のままとし、主役となる抽象構図にしないでください。
```
