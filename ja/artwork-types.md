# オンデマンド印刷にはどのような種類のデザインが適していますか?

まずはイメージを導くものから始めて、それがどのように配置されているかを探ってください。第一印象から次の作品まで、5 つのアートワーク形式。

## 抽象表現

形、線、マーク、色は、明確なオブジェクト参照なしで導き出されます。

121 のクリエイティブな方向性を探る↗](artwork-types/abstract.md)

## イメージを導くものを選択してください

際立った主役はパターン化された地面を持ち、主役主導のままにすることができます。認識可能な幾何学的または様式化された主役もそのファミリーに属します。非具象的な作品は抽象化に属します。以下の 5 つのアートワーク形式すべてのテキスト、レタリング、背景のデザインを確認してください。

## 文字とレタリング

<a id="text-role"></a>

ビジュアルフォーム · 8

### テキストと主役の役割

<a id="text-role-group-word-g20"></a>

ラベルや音声からサウンド、バッジ、タイトル画像、背景、アクセント、共同リードまで、テキストに割り当てられた視覚的な役割を比較します。

<a id="form-lettering-20-0"></a>

![識別ラベル — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-20-0.svg)

##### 識別ラベル

表現を使用して、写真の被写体が何であるかを正確に識別します。

<a id="form-lettering-20-2"></a>

![吹き出し — 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-20-2.svg)

##### 吹き出し

被験者が話した言葉を、目に見える吹き出しの中に入れます。

<a id="form-lettering-20-4"></a>

![サウンドレタリング — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-20-4.svg)

##### サウンドレタリング

喉を鳴らす、轟音、衝撃、その他のノイズを表す効果音を被験者の周りに置きます。

<a id="form-lettering-20-5"></a>

![バッジの組み合わせ – ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-20-5.svg)

##### バッジの組み合わせ

文言と画像を組み合わせて、バッジ、シール、紋章、またはチームのエンブレムのデザインを作成します。

<a id="form-lettering-20-6"></a>

![見出しとイラスト — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-20-6.svg)

##### 見出しとイラスト

文言でテーマを述べ、主題はその説明として機能させます。

<a id="form-lettering-20-7"></a>

![テキストの背景の壁 — ビジュアル スタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-20-7.svg)

##### テキスト背景の壁

画像を焦点として保ちながら、被写体の後ろで控えめな単語やフレーズを繰り返します。

<a id="form-lettering-20-8"></a>

![小さな主役を大きな文字で — 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-20-8.svg)

##### 大きな文字で小さな件名

レタリングがデザインの大部分を占めるようにし、小さな主役を遊び心のあるディテールとして使用します。

<a id="form-lettering-20-9"></a>

![テキストと画像の同等のリード — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-20-9.svg)

##### テキストと画像のリードが等しい

文言と写真の主役を同じように目立つようにして、一緒にメッセージを伝えます。

<a id="text-meaning"></a>

ビジュアルフォーム · 10

### テキストと主役の間の意味的な関係

<a id="text-meaning-group-word-g21"></a>

ネーミング、アイデンティティ、態度、感情、ストーリー、ユーモア、ダジャレ、判じ絵の論理、パーソナライゼーション、またはシリーズの連続性を通じて、言葉遣いがイメージとどのように関連しているかを比較します。

<a id="form-lettering-21-0"></a>

![直接的な命名 - 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-0.svg)

##### 直接的なネーミング

猫の名前の横に猫を置くなど、写真の被写体とそれに対応する名前を組み合わせます。

<a id="form-lettering-21-1"></a>

![アイデンティティステートメント — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-1.svg)

##### アイデンティティステートメント

職業、興味、場所、コミュニティ、または登場人物の役割を通じて主役を特定します。

<a id="form-lettering-21-2"></a>

![態度表明 — 視覚的研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-2.svg)

##### 態度表明

画像で人物像を確立し、言葉遣いでその態度や生き方を表現します。

<a id="form-lettering-21-3"></a>

![感情の強化 - 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-3.svg)

##### 感情の強化

同じ感情を強めるには、画像と短いフレーズの両方を使用します。

<a id="form-lettering-21-4"></a>

![ストーリーの拡張 — ビジュアル スタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-4.svg)

##### ストーリー拡張

写真の瞬間の背後にある時間、場所、理由、または経験を示す文言を追加します。

<a id="form-lettering-21-5"></a>

![ユーモラスなコントラスト — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-5.svg)

##### ユーモラスなコントラスト

かわいい話題と厳しい主張を組み合わせたり、深刻な話題とカジュアルなコメントを組み合わせたりして、ユーモアを作りましょう。

<a id="form-lettering-21-6"></a>

![言葉遊び — 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-6.svg)

##### 言葉遊び

写真の被写体に、文字通りの言葉遣いに基づいたダジャレ、同音異義語、またはジョークに参加させます。

<a id="form-lettering-21-7"></a>

![テキストと画像のパズル — 視覚的な学習](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-7.svg)

##### 文字と画像のパズル

画像と文言のそれぞれが、組み合わせて初めて意味をなす情報を提供するようにします。

<a id="form-lettering-21-8"></a>

![個人的な記念 — 視覚的な研究](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-8.svg)

##### 個人的な記念

個人の名前、日付、座標、記念の言葉、または専用のアドレス形式を追加します。

<a id="form-lettering-21-9"></a>

![コーディネートされたシリーズ — ビジュアルスタディ](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-9.svg)

##### コーディネートシリーズ

さまざまなテーマとさまざまな単語を組み合わせて、家族、カップル、またはチームのコーディネートされたシリーズを作成します。

### レタリングアートトリートメント

<a id="form-relationship--relation-plain-type"></a>

![活字のみの表現: 文字の形、スケール、配置がデザインを伝えます。](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/legacy-relationship--relation-plain-type-1.svg)

#### 型のみの式

文字の形、スケール、配置がデザインを伝えます。

<a id="form-letter-art--letter-outline"></a>

![アウトライン レタリング: 文字のアウトラインはデザインを引き継ぎますが、内部のほとんどは開いたままです。](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/legacy-letter-art--letter-outline-1.svg)

#### アウトラインレタリング

文字の輪郭にはデザインが引き継がれていますが、内部のほとんどは開いたままになっています。

<a id="form-letter-art--letter-stretch"></a>

![引き伸ばされたタイプまたは圧縮されたタイプ: 文字の縦横比が明らかに伸びたり、狭くなったり、広がったりします。](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/legacy-letter-art--letter-stretch-1.svg)

#### 伸縮タイプまたは圧縮タイプ

文字の縦横比が明らかに長くなったり、狭くなったり、広がったりします。

<a id="form-letter-art--letter-wave"></a>

![曲線または波状タイプ: 文字は、目に見える上昇と下降のリズムを伴う曲線または波に従います。](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/legacy-letter-art--letter-wave-1.svg)

#### 湾曲または波形タイプ

文字は、目に見える上昇と下降のリズムを伴う曲線または波に従います。

<a id="form-letter-art--letter-perspective"></a>

![斜めの遠近タイプ: レタリングの幅全体で見かけのスケールが変化し、奥行きが示唆されます。](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/legacy-letter-art--letter-perspective-1.svg)

#### 斜めパースタイプ

レタリングは幅全体にわたって見かけのスケールを変化させ、奥行きを示唆します。

<a id="form-letter-art--letter-fracture"></a>

![分割および移動型: 元の単語は認識可能なままで、文字フォームが移動した部分に切り取られます。](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/legacy-letter-art--letter-fracture-1.svg)

#### 分割変位型

文字の形は、元の単語が認識可能な状態のまま、ずれた部分に切り取られます。

<a id="form-letter-art--letter-texture"></a>

![画像またはテクスチャが埋め込まれたタイプ: パターン、画像、または素材の詳細が文字の内側を埋めます。](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/legacy-letter-art--letter-texture-1.svg)

#### 画像またはテクスチャが埋め込まれたタイプ

パターン、画像、または素材の詳細が文字の内側を埋めます。

##### オービタルレタリング

コードによる研究では、構成と視覚的処理を比較します。メディアとスタイルの例は概念的なものです。これらの方向は、画像モデルを使用して個別にテストされていません。生成されたテキスト、透明度、リピートエッジを確認します。
