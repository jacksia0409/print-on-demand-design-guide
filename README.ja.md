## クリエイティブな方向性をコピーして自分のものにしましょう


このリポジトリには、各言語で 123 の公開 AI 指示が含まれています。これらは、視覚的な目標を平易な言葉で説明します。画像対応 AI ツールで使用したり、選択した方向で既存のプロンプトを書き直すようにアシスタントに依頼したりできます。完全な文言については、以下の例を開いてください。

<details>
<summary><strong>主役を中央に配置</strong> — 主要な被写体を明確な中心位置に置きます。</summary>

1 つの主要な被写体が中央近くに位置し、その周りにスペースがあります。

```text
目指す表現: 教科主導 → 単一教科 → 教科中心

入力と出力: 画像が与えられた場合は、その画像をこの表現に合わせて調整してください。プロンプトが与えられた場合は、画像生成にそのまま使える完全なプロンプトに書き直してください。

目指す構成: 一貫した焦点の主役を 1 つ選択し、その視覚的中心を中央付近に置きます。構図の焦点が安定するように、スケールと周囲のスペースを調整します。

背景: 既存の背景の内容、表現方法、配色を参考にし、目指す構成に合わせて調整してください。背景がない場合、または単なる無地や透明の場合は、テーマに合った背景表現を作成してください。単色、透明、その他の背景について明示的な指定があれば、その指定を優先してください。

文字の扱い: 元画像ではっきり読める文字とその言語を維持し、見せ方を調整してください。読めない文字を復元できたと主張しないでください。文字が指定されていない場合は、主なモチーフ、動き、構成を隠さない短い関連フレーズを補助的に加えてください。既存の文字は目指す視覚的な優先順位に合わせ、文字を入れないという明示的な指定には従ってください。

維持と調整: 中心となるテーマと、元の対象を識別できる特徴を維持してください。元の表現方法と配色を出発点とし、選んだ表現に必要な範囲だけ変更してください。新たに作成した内容を、元画像に存在していたものとして説明しないでください。明示的な入力条件と、目指す結果に必要な条件が矛盾する場合は、両方を満たしたと主張せず、その矛盾を説明してください。

適用範囲と制約: センタリングには鏡面対称性は必要ありません。複数の独立した主役を同じ重点で配布することは避けてください。
```

</details>

<details>
<summary><strong>主役の周囲のテキスト</strong> — 文言を別のブロックに入れるのではなく、件名を囲みます。</summary>

単語は、画像の周囲の円弧または外側のパスをたどります。

```text
目指す表現: 主役主導 → テキストと主役の関係 → 主役の周囲のテキスト

入力と出力: 画像が与えられた場合は、その画像をこの表現に合わせて調整してください。プロンプトが与えられた場合は、画像生成にそのまま使える完全なプロンプトに書き直してください。

目指す構成: 被写体の識別特徴を保持し、円弧、部分的なリング、またはその周りの完全なリングに沿ってテキストを配置します。被写体からの間隔、向き、距離を調整します。

背景: 既存の背景の内容、表現方法、配色を参考にし、目指す構成に合わせて調整してください。背景がない場合、または単なる無地や透明の場合は、テーマに合った背景表現を作成してください。単色、透明、その他の背景について明示的な指定があれば、その指定を優先してください。

文字の扱い: 元画像ではっきり読める文字とその言語を維持し、見せ方を調整してください。読めない文字を復元できたと主張しないでください。文字が指定されていない場合は、主なモチーフ、動き、構成を隠さない短い関連フレーズを補助的に加えてください。既存の文字は目指す視覚的な優先順位に合わせ、文字を入れないという明示的な指定には従ってください。

維持と調整: 中心となるテーマと、元の対象を識別できる特徴を維持してください。元の表現方法と配色を出発点とし、選んだ表現に必要な範囲だけ変更してください。新たに作成した内容を、元画像に存在していたものとして説明しないでください。明示的な入力条件と、目指す結果に必要な条件が矛盾する場合は、両方を満たしたと主張せず、その矛盾を説明してください。

適用範囲と制約: 完全な円はオプションです。ランダムに小さな単語を散在させるのではなく、周囲の軌跡と読みやすい方向を明確に保ちます。
```

</details>

<details>
<summary><strong>ずらしリピート</strong> — リピート行をオフセットしてパターンのリズムを変更します。</summary>

隣接する行または列は、繰り返しシステム内で一定の量だけシフトします。

```text
目指す表現: パターン→シームレスリピート→オフセットリピート

入力と出力: 画像が与えられた場合は、その画像をこの表現に合わせて調整してください。プロンプトが与えられた場合は、画像生成にそのまま使える完全なプロンプトに書き直してください。

目指す構成: 隣接する行または列間の安定したオフセット関係を含むタイルを構築します。反対側のエッジの継続を含む、モチーフの方向、間隔、密度を調整します。

背景: 背景パレットとモチーフを参照し、同じ繰り返し単位内で背景と前景をデザインします。存在しない場合は、関連するベースカラーまたは定期的に継続できるバッキングを作成します。完全な画像タイルを自動的に取得するのではなく、一致しないソース背景を再構築します。

文字の扱い: ソースの文言とその言語を明確に読みやすい状態に保ち、その表現を調整します。読めないテキストを回復したと主張しないでください。言葉が指定されていない場合は、サポートモチーフとしてテーマに関連した短い言葉やフレーズを作成します。シームレスなタイリングが必要な場合は、繰り返し単位に文言を含めて、スペル、エッジの継続性、読みやすさをチェックします。そうしないとシームレス性が保証されません。テキストなしの明示的なリクエストを尊重します。

維持と調整: 中心となるテーマと、元の対象を識別できる特徴を維持してください。元の表現方法と配色を出発点とし、選んだ表現に必要な範囲だけ変更してください。新たに作成した内容を、元画像に存在していたものとして説明しないでください。明示的な入力条件と、目指す結果に必要な条件が矛盾する場合は、両方を満たしたと主張せず、その矛盾を説明してください。

適用範囲と制約: ずらし方はデザインによって変えられますが、全体として一定の繰り返し周期が必要です。個々のモチーフをいくつか移動しただけでは、継ぎ目なく繰り返せるパターンにはなりません。

出力の確認: 横方向、縦方向、4枚を並べた状態で、継ぎ目、リズム、下地の色の連続性を確認してください。確認していない場合や、ツールで保証できない場合は、継ぎ目のない繰り返しを検証済みだと主張しないでください。
```

</details>

## PodPlo で次のステップに進みましょう


アイデアや語彙が必要なときにここを読んでください。独自のイメージを操作する準備ができたら、PodPlo を開き、イメージ Skill を選択するか、ソース要素を探索します。

1. ソース画像またはデザインアイデアを選択します。
2. 必要な変更に一致する Skill を開きます。
3. 必要な画像と独自の言葉を入力してください。
4. 生成設定とクレジット見積を確認し、確認します。

## いくつかの便利な区別


**PodPlo 外の公共ルートを使用できますか?**

視覚的な目標を平易な言葉で説明します。これらをイメージ対応ツールに適応させたり、それらを使用してプロンプトを書き換えたりすることができます。結果はモデル、入力、設定によって異なります。

**図は生成されたサンプルですか?**

小さな視覚形式の図は、コードで描画された概念図です。写真とアートワークの例は、既存の公開ガイドと Skill ショーケース画像です。公開されている AI の指示はすべて個別にテストされているわけではなく、製品のモックアップは製造結果を確立するものではありません。

**これは POD ストアを運営するためのガイドですか?**

焦点は、視覚的な構造、ソース素材、創造的な変換、製品のアイデアなどの画像の作成です。ストアのセットアップ、リストの自動化、フルフィルメントは、このガイドの創造的な焦点の外にあります。

紛らわしい例や追加する価値のあるトピックは見つかりましたか? [改善を提案する](https://github.com/jacksia0409/print-on-demand-design-guide/issues/new)。ガイドがクリエイティブな作業に役立つ場合は、スターを付けると再度見つけやすくなります。
