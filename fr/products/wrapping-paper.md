# Papier d'emballage

Répétez un motif sur une feuille entière de papier cadeau, puis ajoutez des détails de fête ou des éléments personnalisés.

<a id="product-overview"></a>

## Idées de design pour ce produit

### Construisez le design à partir d’une seule répétition

Les personnages, les icônes et les détails personnels peuvent être répétés à différentes échelles pour créer une feuille coordonnée. Un motif répété aéré laissant davantage d’espace ; un motif répété dense d’icônes de fête ; un nom répété au sein du motif.

## Prévisualiser le design sur le produit

### Prévisualisez-le sur une boîte emballée

L'aperçu AI montre comment la même répétition crée différents moments sur le dessus, les côtés et les plis d'une boîte emballée.

- Une répétition lâche laisse plus d'espace ouvert

- Une répétition dense maintient le motif visible à travers les plis

- Un nom peut se répéter à la même échelle que les autres motifs
