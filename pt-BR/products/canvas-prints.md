# Impressões em tela e emolduradas

Transforme uma ilustração ou foto favorita em arte em tela para a casa.

<a id="product-overview"></a>

## Ideias de design para este produto

### Dê a uma imagem favorita sua própria parede

Use um retrato de família, uma paisagem ampla ou um elemento principal bem-definido para criar uma tela adequada ao ambiente. Um retrato de família em camadas; uma paisagem ampla; um elemento principal bem-definido sobre um fundo simples.

## Visualize o design no produto

### Visualize a tela na parede

A visualização de IA coloca o retrato, a paisagem ou o gráfico em uma sala para que você possa comparar as composições.

- Um retrato próximo mantém as pessoas proeminentes

- Uma ampla paisagem preenche mais a parede

- Um fundo simples mantém a atenção no elemento principal
