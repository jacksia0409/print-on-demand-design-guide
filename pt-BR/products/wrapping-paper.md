# Papel de embrulho

Repita um motivo em uma folha inteira de papel de embrulho e, em seguida, adicione detalhes do feriado ou elementos personalizados.

<a id="product-overview"></a>

## Ideias de design para este produto

### Construa o design a partir de uma repetição

Personagens, ícones e detalhes pessoais podem ser repetidos em diferentes escalas para criar uma planilha coordenada. Uma repetição solta com mais espaço aberto; Uma repetição densa de ícones de feriados; Um nome repetido dentro do padrão.

## Visualize o design do produto

### Visualize-o em uma caixa embrulhada

A visualização da IA mostra como a mesma repetição cria momentos diferentes na parte superior, nas laterais e nas dobras de uma caixa embrulhada.

- Uma repetição solta deixa mais espaço aberto

- Uma repetição densa mantém o padrão visível nas dobras

- Um nome pode repetir-se na mesma escala que os outros motivos
