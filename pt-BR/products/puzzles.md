# Quebra-cabeças

Crie obras de arte de quebra-cabeças a partir de uma cena detalhada, foto de família ou mundo ilustrado.

<a id="product-overview"></a>

## Ideias de design para este produto

### Preencha a imagem com detalhes úteis

Rostos, mudanças de cor e objetos distintos dão a cada área do quebra-cabeça algo reconhecível. Uma cena ilustrada detalhada; Retrato de família com objetos pessoais; Uma cena com marcos visuais distintos.

## Visualize o design no produto

### Visualize a imagem completa do quebra-cabeça

A visualização da IA mostra como rostos, cores e pequenas pistas visuais se espalham pela imagem completa do quebra-cabeça.

- Varie a cena em toda a imagem

- Use rostos como pontos focais claros

- Repita pequenos motivos para conectar diferentes áreas
