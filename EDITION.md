# Edition notes

This multilingual edition was prepared on November 3, 2026 from the public
PodPlo Guide snapshot exported on November 2, 2026.

- Ten languages: English, Simplified Chinese, Brazilian Portuguese, Spanish,
  French, German, Arabic, Russian, Japanese, and Hindi.
- 1,650 exported article pages: the same 165 articles in each language.
- Each language also has a contents page, a complete public AI directions
  collection, and a reading index with four instruction parts: 172 documents per
  language, 1,720 in total, plus ten root READMEs.
- 1,388 current visual forms in 128 groups, with original identifiers preserved.
- 123 public creative directions in each language, also collected as copyable text.
- The original diagram and direction order is preserved. Removed entries stay removed.
- Diagrams use immutable, versioned PodPlo CDN URLs. Other publicly displayed Guide images use their public CDN or website URL.
- Links between exported Guide pages point to Markdown in this repository. Product actions and links outside the Guide lead to PodPlo.
- Concept illustrations and AI mockups retain the qualifications shown in the Guide.

## Translation and navigation

The eight added translations use English as their source. They were generated
with Google Translate, with editorial terminology overrides, sampled reading
checks, and automated checks for document coverage, markup, anchors, links,
images, instruction paragraphs, and manifest hashes. They have not undergone
independent, page-by-page native-speaker review. Improvements are welcome via
issues or pull requests.

All chapters, captions, image descriptions, and the 123 copyable public AI
directions are translated. Skill names used as product identities, PodPlo, and
the wording in original example images may remain unchanged. Shared public
images are not redrawn or retranslated. No new image-generation or manufacturing
validation is claimed.

Language selectors link to the equivalent chapter in each language. Filenames,
slugs, explicit anchor identifiers, diagram URLs, and article ordering are
preserved. Arabic documents use right-to-left reading direction, with an isolated
left-to-right language selector.

The instruction reading index links to four bounded parts (1–31, 32–62, 63–93, and 94–123).
The split preserves every complete instruction and avoids GitHub preview limits
for longer translations. The original complete collection remains available as
a raw download. Reading actions point to the split index in every language.

New-language documents retain the existing English PodPlo website destinations;
translation of this repository does not establish localized website routes.
README and contents-page notices explain this before readers follow website
links. Chinese website links retain their existing destinations.

The complete document list and SHA-256 hashes are in `data/manifest.json`.
Translation catalogs and the terminology overrides are included for reproducible,
offline rebuilding. See [maintenance instructions](MAINTENANCE.md).

This is a content snapshot, not an automatic synchronization service. Some links may lead to a newer or older website edition while Guide changes are being released.

The repository does not include application source code, account data, private user results, private Skill instructions, hidden references, or production configuration. No standalone Skill catalogue or Discover image collection is included in this edition.
