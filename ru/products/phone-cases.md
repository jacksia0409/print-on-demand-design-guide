# Чехлы для телефонов

Создайте вертикальный дизайн чехла для телефона из портрета, повторяющегося рисунка или персонализированного изображения.

<a id="product-overview"></a>

## Идеи дизайна для этого продукта

### Используйте вертикальный формат

Для чехлов для телефонов подходят вытянутые вертикальные объекты, рассеянные мотивы и личные детали, встроенные в изображение. Портрет в обрамлении небольших символов; Повторяющийся узор по всей поверхности; Имя, встроенное в рисунок.

## Предварительный просмотр дизайна продукта

### Посмотрите весь чехол

Предварительный просмотр AI показывает вертикальную композицию и пространство вокруг камеры.

- Вертикальный главный объект использует высоту чехла

- Мелкие повторяющиеся мотивы создают ровный узор.

- Яркий фоновый цвет определяет общий вид
