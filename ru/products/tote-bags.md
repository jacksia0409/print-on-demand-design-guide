# Сумки-тоут

Используйте переднюю часть сумки для нанесения жирного рисунка по центру, короткого сообщения или повторяющегося рисунка.

<a id="product-overview"></a>

## Идеи дизайна для этого продукта

### Дизайн, который люди могут носить с собой

Центрированное изображение, крупные буквы и компактные группы мотивов — все это соответствует широкой передней панели сумки. Яркая центрированная графика; Короткое, читаемое сообщение; Группа объектов одной темы.

## Предварительный просмотр дизайна продукта

### Предварительный просмотр на сумке

Используйте предварительный просмотр AI, чтобы сравнить смелую графику с простым повседневным дизайном.

- Центрированное изображение создает сбалансированный макет.

- Крупный шрифт облегчает чтение сообщения.

- Мотив меньшего размера легче сочетать с разными нарядами.
