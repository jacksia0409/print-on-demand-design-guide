# 公开 AI 创作指令

以下是 Guide 的公开创作指令，不是 Skill 隐藏规则。图例属于概念示意，生成结果仍需检查。

[← 分两卷阅读全部 123 条创作指令，每条均附可复制的完整文本。](INDEX.md)

## 满幅覆盖

肌理覆盖整个画面，材料质感就是主要内容和底层。

```text
目标类型：肌理型 → 组织方式 → 满幅覆盖

输入与输出：输入图片时，按本方向调整图片；输入提示词时，将其改写为一段可直接用于生图的完整提示词。

目标结构：将选定肌理延展到整个画幅，保持质感尺度、色彩与整体密度协调，使画面边缘也有连续的材料信息，不留额外独立底板。

背景处理：参考已有背景中的颜色或材料线索，转入主要肌理自身；没有背景时创造与主题相关的满幅质感。此方向下肌理与底层合一，不另外叠放一个声称仍可见的独立背景。

文字处理：已有清晰文字时保留原文与语言，参考原有表现方式调整；模糊文字不要猜作已还原。没有文字时创作一句与主题相关的简短文案，作为辅助表达，不遮挡关键主体、动作或主要结构；已有文字的主次按目标方向调整。输入明确要求不加字时遵从。

保留与调整：保留与目标相关的材质、表面特征、配色和气氛，不强制保留物体外轮廓或完整场景；输入没有材料线索时按指定方向创造效果，不冒称识别了原图的真实材质。新增内容不说成输入中已有的内容。输入明确限制与目标必要条件冲突时指出冲突，不声称已同时满足。

类型边界：满幅覆盖不等于可无缝拼接；内容与背景在此合一，不能再要求它后面另有可见的完整背景。
```


## 局部片段

肌理只出现在局部区域，外围保留其他背景或透明空间。

```text
目标类型：肌理型 → 组织方式 → 局部片段

输入与输出：输入图片时，按本方向调整图片；输入提示词时，将其改写为一段可直接用于生图的完整提示词。

目标结构：将输入肌理或由主题提炼的质感集中在一个局部片段内，边界可规则、自然或渐隐，保留外围空间供背景或辅助信息承接。

背景处理：参考已有背景的材质、配色与氛围，缺少时创造相关的表面处理。局部片段可以另配底层，满幅肌理则与背景合一；避免新增醒目的物体或故事场景取代质感表达。

文字处理：已有清晰文字时保留原文与语言，参考原有表现方式调整；模糊文字不要猜作已还原。没有文字时创作一句与主题相关的简短文案，作为辅助表达，不遮挡关键主体、动作或主要结构；已有文字的主次按目标方向调整。输入明确要求不加字时遵从。

保留与调整：保留与目标相关的材质、表面特征、配色和气氛，不强制保留物体外轮廓或完整场景；输入没有材料线索时按指定方向创造效果，不冒称识别了原图的真实材质。新增内容不说成输入中已有的内容。输入明确限制与目标必要条件冲突时指出冲突，不声称已同时满足。

类型边界：肌理仍是主要视觉内容；片段形状若变成明确物体，且主要表达转向物体身份，应按主体型判断。
```

## 几何构成

用几何形状、线条与比例关系组成画面，没有明确的物体指向。

```text

背景处理：参考已有背景的色彩、节奏和气氛，缺少时创造与主题相关的底层或空间关系，让背景弱于主要抽象构成。已有具象环境可简化为辅助线索，不让其取代非具象表达。

文字处理：已有清晰文字时保留原文与语言，参考原有表现方式调整；模糊文字不要猜作已还原。没有文字时创作一句与主题相关的简短文案，作为辅助表达，不遮挡关键主体、动作或主要结构；已有文字的主次按目标方向调整。输入明确要求不加字时遵从。

保留与调整：保留输入的主题气氛、配色、节奏或方向，允许弱化或移除具体对象识别特征，以实现非具象表达；不同时要求保留原物体外形。新增内容不说成输入中已有的内容。输入明确限制与目标必要条件冲突时指出冲突，不声称已同时满足。

类型边界：若几何形状仍明确组成某个对象，应归主体的几何化；抽象几何可以规则，也可以不规则。
```
