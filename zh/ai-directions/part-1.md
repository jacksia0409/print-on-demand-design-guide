# 公开 AI 创作指令

以下是 Guide 的公开创作指令，不是 Skill 隐藏规则。图例属于概念示意，生成结果仍需检查。

[← 分四卷阅读全部 123 条创作指令，每条均附可复制的完整文本。](INDEX.md)

## 1 主体型

以一个或多个明确对象、文字或图文组合作为画面核心，背景与装饰围绕它展开。

```text
目标类型：主体型

输入与输出：输入图片时，按本方向调整图片；输入提示词时，将其改写为一段可直接用于生图的完整提示词。

目标结构：确定输入的核心对象或文字，以清楚的视觉主次组织画面。可选择单主体、多主体，或补充图文关系，并让背景服务于核心表达。

背景处理：已有背景时参考其中的内容、风格和配色，调整成服务于目标结构的背景；没有背景或只有纯色、透明底时，依据主题创造相关背景处理。若已明确指定纯色、透明或其他背景要求，按该要求实现。

文字处理：已有清晰文字时保留原文与语言，参考原有表现方式调整；模糊文字不要猜作已还原。没有文字时创作一句与主题相关的简短文案，作为辅助表达，不遮挡关键主体、动作或主要结构；已有文字的主次按目标方向调整。输入明确要求不加字时遵从。

保留与调整：保留输入的核心主题与关键识别特征；画风和配色以原输入为基础，仅在实现本方向所必需时调整。新增内容不说成输入中已有的内容。输入明确限制与目标必要条件冲突时指出冲突，不声称已同时满足。

类型边界：不以环境空间、整体花纹、材料质感或无对象抽象构成取代明确主体。
```


## 2 场景型

主体、环境与空间或情节共同构成画面，让人理解一种情境。

```text
目标类型：场景型

输入与输出：输入图片时，按本方向调整图片；输入提示词时，将其改写为一段可直接用于生图的完整提示词。

目标结构：依据输入核心主题安排主体、环境和空间关系，可表达事件、安静情境、风景或生活局部。原输入缺乏环境时，创造与主题相关的环境。

背景处理：已有背景时参考原有地点、环境元素和气氛，完善支撑目标场景的空间关系；没有背景或只有纯色、透明底时，根据主题创造相关环境。不要仅用一片装饰花纹代替必要的情境。

文字处理：已有清晰文字时保留原文与语言，参考原有表现方式调整；模糊文字不要猜作已还原。没有文字时创作一句与主题相关的简短文案，作为辅助表达，不遮挡关键主体、动作或主要结构；已有文字的主次按目标方向调整。输入明确要求不加字时遵从。

保留与调整：保留输入的核心主题与关键识别特征；画风和配色以原输入为基础，仅在实现本方向所必需时调整。新增内容不说成输入中已有的内容。输入明确限制与目标必要条件冲突时指出冲突，不声称已同时满足。

类型边界：场景型不一定需要动作；若只是在孤立物体背后加装饰而不表达情境，应归主体型。
```


## 3 纹样型

```text

目标结构：从输入提取相关元素，建立明确的重复、交错、环绕或有限排列规律。依据用途确定是否需要边缘接续；需要无缝时处理整体重复单元。

背景处理：已有背景时参考其中的内容、风格和配色，调整成服务于目标结构的背景；没有背景或只有纯色、透明底时，依据主题创造相关背景处理。若已明确指定纯色、透明或其他背景要求，按该要求实现。

保留与调整：保留输入的核心主题与关键识别特征；画风和配色以原输入为基础，仅在实现本方向所必需时调整。新增内容不说成输入中已有的内容。输入明确限制与目标必要条件冲突时指出冲突，不声称已同时满足。

类型边界：不是所有规则网格都属于纹样；以逐项展示不同素材为主时属于集合型，无缝需另作拼接验证。
```


## 4 肌理型

以自然、材料或人工痕迹形成的表面质感为主要内容。

```text
目标类型：肌理型

输入与输出：输入图片时，按本方向调整图片；输入提示词时，将其改写为一段可直接用于生图的完整提示词。

目标结构：提取输入中的配色、材料与气氛，转化为以表面细节为主的画面。可采用满幅、局部片段或层叠组织，弱化与质感无关的独立对象。

背景处理：参考已有背景的材质、配色与氛围，缺少时创造相关的表面处理。局部片段可以另配底层，满幅肌理则与背景合一；避免新增醒目的物体或故事场景取代质感表达。

文字处理：已有清晰文字时保留原文与语言，参考原有表现方式调整；模糊文字不要猜作已还原。没有文字时创作一句与主题相关的简短文案，作为辅助表达，不遮挡关键主体、动作或主要结构；已有文字的主次按目标方向调整。输入明确要求不加字时遵从。

保留与调整：保留与目标相关的材质、表面特征、配色和气氛，不强制保留物体外轮廓或完整场景；输入没有材料线索时按指定方向创造效果，不冒称识别了原图的真实材质。新增内容不说成输入中已有的内容。输入明确限制与目标必要条件冲突时指出冲突，不声称已同时满足。

类型边界：突出具体物品的外形或完整环境时，分别判断主体型或场景型；肌理不等于任何无主体画面。
```


## 5 抽象型

以形状、线条、笔触和色彩关系表达，不指向明确的具体对象。

```text
目标类型：抽象型

输入与输出：输入图片时，按本方向调整图片；输入提示词时，将其改写为一段可直接用于生图的完整提示词。

目标结构：从输入提取色彩、节奏、方向或情绪，转化成几何、有机形态、笔触或色域构成，调整形状关系与留白，不以识别原物体为主要目的。

背景处理：参考已有背景的色彩、节奏和气氛，缺少时创造与主题相关的底层或空间关系，让背景弱于主要抽象构成。已有具象环境可简化为辅助线索，不让其取代非具象表达。

文字处理：已有清晰文字时保留原文与语言，参考原有表现方式调整；模糊文字不要猜作已还原。没有文字时创作一句与主题相关的简短文案，作为辅助表达，不遮挡关键主体、动作或主要结构；已有文字的主次按目标方向调整。输入明确要求不加字时遵从。

保留与调整：保留输入的主题气氛、配色、节奏或方向，允许弱化或移除具体对象识别特征，以实现非具象表达；不同时要求保留原物体外形。新增内容不说成输入中已有的内容。输入明确限制与目标必要条件冲突时指出冲突，不声称已同时满足。

类型边界：仍明确识别为某个对象的风格化处理属于主体型；以材料表面质感为主时属于肌理型。
```


## 居中

一个主要对象放在画面中心，周围留有空间，让人一眼知道重点是什么。

```text
目标类型：主体型 → 单主体 → 居中

背景处理：已有背景时参考其中的内容、风格和配色，调整成服务于目标结构的背景；没有背景或只有纯色、透明底时，依据主题创造相关背景处理。若已明确指定纯色、透明或其他背景要求，按该要求实现。

保留与调整：保留输入的核心主题与关键识别特征；画风和配色以原输入为基础，仅在实现本方向所必需时调整。新增内容不说成输入中已有的内容。输入明确限制与目标必要条件冲突时指出冲突，不声称已同时满足。

类型边界：居中指主体的整体视觉重心靠近中心，不要求每个细节左右对称；不要把多个独立对象等量分散展示。
```






## 上下组合

多个主体沿上下方向组合，形成纵向的整体。

