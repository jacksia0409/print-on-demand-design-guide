# 公开 AI 创作指令

以下是 Guide 的公开创作指令，不是 Skill 隐藏规则。图例属于概念示意，生成结果仍需检查。

[← 分四卷阅读全部 123 条创作指令，每条均附可复制的完整文本。](INDEX.md)

## 肌理背景

文字和主体的关系采用这一背景处理：底层有纸纹、颗粒或其他材质感，用来衬托前方内容。

```text
目标类型：主体型 → 文字和主体的关系 → 背景处理 → 肌理背景

输入与输出：输入图片时，按本方向调整图片；输入提示词时，将其改写为一段可直接用于生图的完整提示词。

目标结构：保留图文的主题与核心关系，协调文字和图像的主次、位置及可读性，不擅自把辅助文字放大为主标题。

背景处理：已有背景肌理时参考其材料、颜色和疏密；没有时依据主题创造相关的低干扰表面质感。协调肌理尺度与对比，让它作为底层而非新的视觉中心。

文字处理：已有清晰文字时保留原文与语言，参考原有表现方式调整；模糊文字不要猜作已还原。没有文字时创作一句与主题相关的简短文案，作为辅助表达，不遮挡关键主体、动作或主要结构；已有文字的主次按目标方向调整。输入明确要求不加字时遵从。

保留与调整：保留输入的核心主题与关键识别特征；画风和配色以原输入为基础，仅在实现本方向所必需时调整。新增内容不说成输入中已有的内容。输入明确限制与目标必要条件冲突时指出冲突，不声称已同时满足。

类型边界：肌理背景不应自动变成一件具体物品或完整故事场景。主类本身为肌理型时，要区分主要肌理片段与辅助背景肌理。
```


## 场景背景

文字和主体的关系采用这一背景处理：主要内容后方有环境作为衬托，环境与主题相关。

```text
目标类型：主体型 → 文字和主体的关系 → 背景处理 → 场景背景

输入与输出：输入图片时，按本方向调整图片；输入提示词时，将其改写为一段可直接用于生图的完整提示词。

背景处理：已有背景时参考地点、环境元素和氛围，调整为适合主要内容的空间；没有背景或只有纯色、透明底时，围绕主题创造相关环境，协调方向、尺度与前后关系。

文字处理：已有清晰文字时保留原文与语言，参考原有表现方式调整；模糊文字不要猜作已还原。没有文字时创作一句与主题相关的简短文案，作为辅助表达，不遮挡关键主体、动作或主要结构；已有文字的主次按目标方向调整。输入明确要求不加字时遵从。

保留与调整：保留输入的核心主题与关键识别特征；画风和配色以原输入为基础，仅在实现本方向所必需时调整。新增内容不说成输入中已有的内容。输入明确限制与目标必要条件冲突时指出冲突，不声称已同时满足。

类型边界：主类为主体、纹样、肌理或抽象时，环境保持辅助；若完整空间或情节转为主要表达，应重新按场景型判断。不要声称任何场景背景都能与原类型同时保持同等主导。
```


## 透明背景

场景型采用这一背景处理：底层保持透明，图案之外没有实色背景；棋盘格只是显示透明的提示。

```text
目标类型：场景型 → 背景处理 → 透明背景

输入与输出：输入图片时，按本方向调整图片；输入提示词时，将其改写为一段可直接用于生图的完整提示词。

目标结构：保留场景自身的空间、环境和已有情节，调整其后方、天空底层或外围承载背景，不把构成场景的环境全部抹掉。

背景处理：已有背景时，参考其中可用的配色、风格或必要主题线索，然后移除作为底层的背景；没有背景时保持透明，不补画一个假底。主体、图案或场景内部必要的颜色可以保留。

文字处理：已有清晰文字时保留原文与语言，参考原有表现方式调整；模糊文字不要猜作已还原。没有文字时创作一句与主题相关的简短文案，作为辅助表达，不遮挡关键主体、动作或主要结构；已有文字的主次按目标方向调整。输入明确要求不加字时遵从。

保留与调整：保留输入的核心主题与关键识别特征；画风和配色以原输入为基础，仅在实现本方向所必需时调整。新增内容不说成输入中已有的内容。输入明确限制与目标必要条件冲突时指出冲突，不声称已同时满足。

类型边界：真实透明需要透明通道，不能把棋盘格或白底画进成品冒充透明。若使用的工具不能输出透明，说明需要后处理。
```

## 渐变背景

场景型采用这一背景处理：底层的颜色或明暗连续过渡，主要内容仍保持突出。

```text
目标类型：场景型 → 背景处理 → 渐变背景

输入与输出：输入图片时，按本方向调整图片；输入提示词时，将其改写为一段可直接用于生图的完整提示词。

背景处理：参考输入背景或主题中的颜色与氛围，建立连续的颜色、明暗或透明度过渡；没有背景时创造与主题相符的渐变底层，协调过渡方向和强度。

文字处理：已有清晰文字时保留原文与语言，参考原有表现方式调整；模糊文字不要猜作已还原。没有文字时创作一句与主题相关的简短文案，作为辅助表达，不遮挡关键主体、动作或主要结构；已有文字的主次按目标方向调整。输入明确要求不加字时遵从。

保留与调整：保留输入的核心主题与关键识别特征；画风和配色以原输入为基础，仅在实现本方向所必需时调整。新增内容不说成输入中已有的内容。输入明确限制与目标必要条件冲突时指出冲突，不声称已同时满足。

类型边界：渐变应有连续过渡；两块边界清楚的平涂颜色不等于渐变。避免强烈变化掩盖主要内容。
```


## 图案背景 · 局部衬底

场景型采用这一背景处理：内容背后有一片局部装饰图案，外围保留未被这片图案覆盖的空间。

```text
目标类型：场景型 → 背景处理 → 图案背景 · 局部衬底

背景处理：已有背景内容时，参考其元素、风格和配色，重组为主要内容后方的一片局部衬底；没有背景或只有纯色、透明底时，创造与主题相关的装饰图案。外围保持透明、原有底色或明确指定的背景。

类型边界：图案可规则或自由组合，但不铺满全图；主要沿外圈包围的属于环绕装饰。主体或主要内容保持主导，不把背景图案当作新增的同等主体。
```
