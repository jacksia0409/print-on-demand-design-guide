# 换个节日，让灵感再次绽放

保留喜欢的主体，添上圣诞的温暖、万圣节的趣味，或情人节的一点浪漫。

<a id="christmas-version"></a>

## 让熟悉画面亮起圣诞灯光

[Make It Christmas](https://podplo.app/skills/make-it-christmas) 让同一个可识别主体，开启温暖的圣诞新章节。

[Make It Christmas](https://podplo.app/skills/make-it-christmas) 会在原主体周围加入灯光、绿植、飘雪或其他协调的圣诞细节。画面多了一章节日故事，同一人物、宠物、图案与文字仍然可识别。

## 给同一段关系添一点心意

[Make It Valentine’s](https://podplo.app/skills/make-it-valentines) 让已有人物、宠物或图案，多一种温暖的关系表达。

[Make It Valentine’s](https://podplo.app/skills/make-it-valentines) 会在已有人物、情侣、宠物或图案周围加入爱心、花朵、温暖色彩或轻柔留言。它庆祝画面里真实存在的关系，不额外虚构新关系。

## 让家庭画面为母亲节绽放

[Make It Mother’s Day](https://podplo.app/skills/make-it-mothers-day) 把家庭图片与准确留言组成温暖致意，完整保留原有人物。

[Make It Mother’s Day](https://podplo.app/skills/make-it-mothers-day) 会在已有人物周围加入花朵、温暖氛围与准确留言。每一位已提供的家人都保留在故事里，不额外添加或替换人物。

![添加母亲节主题前的家庭参考图](https://images.podplo.app/official/skills/podplo-skill-media-20261027/skills/podplo-skill-5-6-before.webp)
