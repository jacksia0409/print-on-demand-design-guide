# 一个灵感，长成一整个系列

用四件套或六件套 Skill 延续同一个主题，让每张图各有变化，放在一起又彼此呼应。八件套示例待补。

<a id="four-piece-series"></a>

## 4PC：看一个灵感分出四条路

[4PC Grid Generator](https://podplo.app/skills/four-piece-grid) 让一张参考图一次显出四个协调的创作方向。

[4PC Grid Generator](https://podplo.app/skills/four-piece-grid) 会把一张参考图展开成四个彼此关联又不相同的构图。主体在系列中保持联系，版式、辅助元素与视觉重心则打开四种可能方向。

## 6PC：让一点灵感长成小系列

[6PC Grid Generator](https://podplo.app/skills/six-piece-grid) 把一张参考图发展成气质相连的六件视觉小系列。

[6PC Grid Generator](https://podplo.app/skills/six-piece-grid) 会把一张参考图扩展成六个协调方向。共同色彩与主体把它们连成一个家族，姿态、取景、装饰或构图则让每一格都有自己的存在感。

## 8PC：在系列出现前，先想象它的全貌

为八张图设定不同角色与一条共同视觉线索；8PC 图像仅是占位，不是已支持生成器。

八件系列仍可以先从每格角色、共同配色与不同视觉任务开始想象。这张图仅是规划占位：PodPlo 当前提供 4PC 与 6PC Skill，没有 8PC 生成器。
