# 把名字与心意，写进设计

把姓名、短句与重要日期融入图案，让想说的话成为设计里特别的一部分。

<a id="name-frame"></a>

## 让一个姓名在图案里绽放

[Floral Name Frame](https://podplo.app/skills/floral-name-frame) 让 ANDREA 这样的准确姓名，在平衡的水彩花卉构图里绽放。

[Floral Name Frame](https://podplo.app/skills/floral-name-frame) 会把 ANDREA 这样的准确姓名放进平衡的水彩花园里。每个新姓名都会改变留白与节奏，让同一花卉灵感再次拥有私人感。

## 让一句短话成为画面主角

[Title–Subject–Subtitle Layout](https://podplo.app/skills/title-subject-subtitle-layout) 把 STAY WILD 与一个图案，组成文字主导的清晰故事。

[Title–Subject–Subtitle Layout](https://podplo.app/skills/title-subject-subtitle-layout) 会让 STAY WILD 这样的短句站到画面前方，图案与可选副句则围绕它展开故事。示例图展示的是这种排版思路，不是自动替换旧图文字。

## 让一个日期把回忆收进徽章

[Circular Badge Layout](https://podplo.app/skills/circular-badge-layout) 把准确日期或年份与一个图案，收成紧凑的纪念徽章。

[Circular Badge Layout](https://podplo.app/skills/circular-badge-layout) 会把 EST. 2024 或 10.12.2024 这样的准确文字环绕在中心图案周围，让事实细节也成为构图一部分。示例图展示的是徽章结构，不是自动替换旧图日期。
