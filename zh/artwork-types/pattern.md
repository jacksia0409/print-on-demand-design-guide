# 纹样型

通过重复与排列形成整体花纹，分为无缝与非无缝；无缝性需要另外检查接续。

#### 朝向与运动路径

相同的排布，也可以因单元朝向不同而改变气质。

<a id="form-pattern-59-0"></a>

![同向排列型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-0.svg)

##### 同向排列型

所有单元朝向一致，强化上下、行进或生长方向。

统一朝向 · 基本单元 · 方向秩序

<a id="form-pattern-59-1"></a>

![双向倒置型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-1.svg)

##### 双向倒置型

正向与倒向单元交替出现，形成上下相反的视觉节奏。

正向单元 · 倒向单元 · 交替关系

<a id="form-pattern-59-2"></a>

![四向交替型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-2.svg)

##### 四向交替型

单元在四个方向间循环切换，让画面弱化单一的阅读方向。

四向单元 · 循环顺序 · 均衡分布

<a id="form-pattern-59-3"></a>

![多向旋转型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-3.svg)

##### 多向旋转型

单元使用多种角度分布，减少整齐排队感，形成全向观看效果。

角度变化 · 多向单元 · 分布区域

<a id="form-pattern-59-4"></a>

![切向环绕型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-4.svg)

##### 切向环绕型

单元的朝向沿圆周切线变化，像绕中心旋转的鱼群或叶片。

环绕路径 · 切向单元 · 旋转方向

<a id="form-pattern-59-5"></a>

![向心汇聚型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-5.svg)

##### 向心汇聚型

单元朝向同一中心，或反向朝外，形成聚拢与扩散的视觉力量。

汇聚中心 · 指向单元 · 向心或离心

<a id="pattern-panel-word-g60-pattern"></a>

<a id="pattern-group-word-g60-pattern"></a>

#### 单元组合与节拍

先把几个元素组成节拍，再重复整个节拍。

<a id="form-pattern-60-0"></a>

![AB 交替型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-0.svg)

##### AB 交替型

两类单元按 ABAB 的顺序交替，依靠形状或色彩差异形成节奏。

A 单元 · B 单元 · 交替序列

<a id="form-pattern-60-1"></a>

![ABC 循环型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-1.svg)

##### ABC 循环型

三类或更多单元以固定顺序循环，形成更长的重复节拍。

多类单元 · 循环顺序 · 完整周期

<a id="form-pattern-60-2"></a>

![主辅节拍型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-2.svg)

##### 主辅节拍型

较大的主单元与较小的辅助元素组合，重复形成主次清晰的图案。

主单元 · 辅助单元 · 组合节拍

<a id="form-pattern-60-3"></a>

![成对单元型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-3.svg)

##### 成对单元型

先将两个相同或相关单元配成一对，再重复这一对，而非孤立地重复单个元素。

配对元素 · 组合单元 · 组间距离

<a id="form-pattern-60-4"></a>

![簇状单元型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-4.svg)

##### 簇状单元型

把多个小元素组成花束、果串或物件簇，再将整簇重复分布。

簇内元素 · 组团轮廓 · 簇间分布

<a id="form-pattern-60-5"></a>

![大小交替型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-5.svg)

##### 大小交替型

大单元与小单元交替排列，以尺度差异代替形状差异建立节奏。

大单元 · 小单元 · 尺度节拍

<a id="form-pattern-60-6"></a>

![多尺度混排型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-6.svg)

##### 多尺度混排型

同一类元素使用多档大小混合铺开，形成前后层次与丰富度。

尺度层级 · 混合单元 · 大小平衡

<a id="form-pattern-60-7"></a>

![等距留白型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-7.svg)

##### 等距留白型

把稳定的空隙作为节拍的一部分，让每个单元保持清晰独立。

单元边界 · 固定空隙 · 留白节奏

<a id="pattern-panel-word-g61-pattern"></a>

<a id="pattern-group-word-g61-pattern"></a>

#### 密度与渐变

通过连续变化引导视线；渐变方向也会影响接边。

<a id="form-pattern-61-0"></a>

![疏散留白型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-0.svg)

##### 疏散留白型

单元之间保留较大空隙，以少量元素形成轻盈、安静的满幅效果。

稀疏单元 · 大面积留白 · 分布平衡

<a id="form-pattern-61-1"></a>

![密集满铺型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-1.svg)

##### 密集满铺型

元素紧密排列、相互靠近甚至局部重叠，让底色退居次要位置。

密集元素 · 小间隙 · 满幅覆盖

<a id="form-pattern-61-2"></a>

![密度渐变型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-2.svg)

##### 密度渐变型

逐渐改变单位面积内的元素数量，形成从疏到密或从密到疏的过渡。

疏区 · 密区 · 密度过渡

<a id="form-pattern-61-3"></a>

![尺度渐变型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-3.svg)

##### 尺度渐变型

单元沿一个方向逐渐变大或变小，产生推进、远近或扩散感。

尺度序列 · 变化方向 · 渐变范围

<a id="form-pattern-61-4"></a>

![方向渐变型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-4.svg)

##### 方向渐变型

单元的旋转角度逐步改变，构成流场、转向或扭动效果。

角度序列 · 转向路径 · 方向流场

<a id="form-pattern-61-5"></a>

![色彩渐变型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-5.svg)

##### 色彩渐变型

保持基本布局，通过单元颜色、明度或饱和度的分级变化形成过渡。

配色序列 · 重复单元 · 色彩过渡

<a id="form-pattern-61-6"></a>

![局部疏密对比型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-6.svg)

##### 局部疏密对比型

在同一画面中安排密集聚集区与安静留白区，制造视觉重心。

聚集区域 · 留白区域 · 疏密边界

<a id="pattern-panel-word-g62-pattern"></a>

<a id="pattern-group-word-g62-pattern"></a>

#### 散布与受控随机

自由感来自分布控制；随机不代表完全没有规则。

<a id="form-pattern-62-0"></a>

![均衡散布型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-0.svg)

##### 均衡散布型

位置不排成明显行列，但通过间距与视觉重量控制，使整体分布均衡。

不规则位置 · 视觉重量 · 均衡空隙

<a id="form-pattern-62-1"></a>

![受控随机型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-1.svg)

##### 受控随机型

限定角度、尺度、最小间距或元素比例后随机放置，兼顾自然与秩序。

随机参数 · 约束范围 · 散布结果

<a id="form-pattern-62-2"></a>

![分区散点型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-2.svg)

##### 分区散点型

不同区域使用不同元素或密度，形成分区明确而边缘自然的散点图案。

分布分区 · 区域单元 · 交界过渡

<a id="form-pattern-62-3"></a>

![群落分布型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-3.svg)

##### 群落分布型

元素先在局部聚成小群，再让多个群落分散到全幅，避免完全均匀。

小群落 · 群间间距 · 全幅分布

<a id="form-pattern-62-4"></a>

![路径散点型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-4.svg)

##### 路径散点型

元素沿隐形的弧线、波线或轨迹散布，远看具有流动方向。

隐形路径 · 沿线单元 · 路径间距

<a id="form-pattern-62-5"></a>

![重叠散点型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-5.svg)

##### 重叠散点型

散点元素允许前后叠压，用遮挡关系形成层次和堆积感。

散点位置 · 前后遮挡 · 叠压层次

<a id="form-pattern-62-6"></a>

![避让留白型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-6.svg)

##### 避让留白型

元素主动避开文字区、主体区或特定轮廓，让空白区域参与图案构图。

保留区域 · 避让边界 · 周边单元

<a id="pattern-panel-word-g68-pattern"></a>

<a id="pattern-group-word-g68-pattern"></a>

#### 纹样元素组合

选择重复的是单个物体、成组物体，还是一段小场景。

<a id="form-pattern-68-0"></a>

![主题物件组合型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-0.svg)

##### 主题物件组合型

围绕同一主题组合多种物件，如烘焙工具、旅行物品或园艺器具，再整体散布。

主题物件 · 元素比例 · 组合分布

<a id="form-pattern-68-1"></a>

![花束散簇型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-1.svg)

##### 花束散簇型

多种花叶先组成完整花束，再以花束为单位平铺或散点分布。

花束内部 · 花束轮廓 · 簇间空隙

<a id="form-pattern-68-2"></a>

![折枝散布型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-2.svg)

##### 折枝散布型

保留局部枝、叶、花的自然连接，以独立折枝分布在画面中。

折枝单元 · 枝叶朝向 · 散布位置

<a id="form-pattern-68-3"></a>

![藤蔓生长型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-3.svg)

##### 藤蔓生长型

用攀爬、转折、分枝的连续植物结构填充画面，让小花叶依附骨架生长。

生长主干 · 分枝节点 · 附生花叶

<a id="form-pattern-68-4"></a>

![风景小景型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-4.svg)

##### 风景小景型

把建筑、山水、树木等组合成独立小景，多个小景以不同方向分布。

小景单元 · 场景间隔 · 观看方向

<a id="form-pattern-68-5"></a>

![叙事片段型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-5.svg)

##### 叙事片段型

重复人物活动、动物互动或生活片段，让每个单元承载一段微型故事。

叙事单元 · 动作关系 · 场景分布

<a id="form-pattern-68-6"></a>

![图文混排型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-6.svg)

##### 图文混排型

将词语、字母、数字与图形混合铺开，通过大小、方向和间距建立节奏。

文字单元 · 图形单元 · 混排节拍

<a id="form-pattern-68-7"></a>

![徽章拼组型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-7.svg)

##### 徽章拼组型

把徽章、标签、印章或标牌作为完整单元，组合成收藏贴纸般的重复图案。

徽章单元 · 内容变化 · 拼组密度

<a id="pattern-panel-word-g69-pattern"></a>

<a id="pattern-group-word-g69-pattern"></a>

#### 线场、点场与连续肌理

不一定以独立 icon 为单元，也可以用连续的线、点和色块形成 pattern。

<a id="form-pattern-69-0"></a>

![平行线场型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-0.svg)

##### 平行线场型

大量平行直线按固定或变化间距铺开，以线宽与间距形成纹理节奏。

平行线 · 线宽变化 · 线间距离

<a id="form-pattern-69-1"></a>

![曲线等高型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-1.svg)

##### 曲线等高型

多条曲线按轮廓逐层偏移，形成等高线、年轮或地形般的连续图案。

基准轮廓 · 偏移曲线 · 曲线密度

<a id="form-pattern-69-2"></a>

![点阵网点型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-2.svg)

##### 点阵网点型

用点的大小、密度或排列方式形成明暗、形状或规律纹理。

点阵单元 · 点径变化 · 密度区域

<a id="form-pattern-69-3"></a>

![颗粒肌理型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-3.svg)

##### 颗粒肌理型

以细小颗粒、短笔触或纤维痕迹铺满画面，强调细密而不显著的重复。

微小颗粒 · 局部密度 · 整体肌理

<a id="form-pattern-69-4"></a>

![斑块云纹型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-4.svg)

##### 斑块云纹型

不规则色块或软边轮廓互相靠近、嵌合，形成云团或斑驳式满幅效果。

不规则斑块 · 块间空隙 · 整体分布

<a id="form-pattern-69-5"></a>

![流体涡纹型 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-5.svg)

##### 流体涡纹型

曲线或色带沿流场弯曲、卷动，形成涡旋、水流或液体般的纹样。

流场方向 · 卷曲中心 · 连续色带

#### 常见几何与织物纹样

这里按可识别的纹样母题命名，可再搭配前面的排列方式。

<a id="form-pattern-72-0"></a>

![波点纹样 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-72-0.svg)

##### 波点纹样

以圆点为主要单元，通过点径、行列、错位与疏密变化形成不同波点效果。

圆点单元 · 点距 · 排列规则

<a id="form-pattern-72-1"></a>

![格子交织纹样 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-72-1.svg)

##### 格子交织纹样

横纵条带交叠产生格子，可通过带宽、条带分组与配色形成细格或大格。

横向条带 · 纵向条带 · 交叠色块

<a id="form-pattern-72-2"></a>

![千鸟格纹样 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-72-2.svg)

##### 千鸟格纹样

用带有尖角的深浅色单元互相嵌合，形成类似破折格的连续视觉效果。

深浅单元 · 尖角轮廓 · 咬合结构

<a id="form-pattern-72-3"></a>

![人字纹样 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-72-3.svg)

##### 人字纹样

倾斜短段按方向交替排列，形成连续的人字或鱼骨式节奏。

倾斜短段 · 方向交替 · 人字拼接

<a id="form-pattern-72-4"></a>

![锯齿山形纹样 — 示意](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-72-4.svg)

##### 锯齿山形纹样

连续 V 形折线或折带形成起伏节奏，可使用等宽或宽窄变化。
