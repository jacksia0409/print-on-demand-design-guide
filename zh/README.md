## 素材类型

认识不同素材适合怎样创作：从独立元素的排版、徽章与纹样，到完整图片的重新构图、文字与主题变化。

## 哪些图案适合做 POD？

从主体、场景到纹样、肌理与抽象，为同一张素材找到不同的表达。看示意、认识边界，再把方向带进图片或提示词。
