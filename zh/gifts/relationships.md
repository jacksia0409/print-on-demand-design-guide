# 把共同故事，留在身边

把姓名、日期、地点与照片，变成只属于一段真实关系的纪念图案。

<a id="dates-and-commitments"></a>

## 让一个日期收住共同承诺

[Floral Name Frame](https://podplo.app/skills/floral-name-frame) 把准确姓名或特别日期，变成温柔的关系纪念图案。

一个准确姓名、日期、地点或共同短句，可以成为周年、婚礼、订婚或异地纪念的安静中心。[Floral Name Frame](https://podplo.app/skills/floral-name-frame) 让这些真实细节在平衡构图里绽放。
