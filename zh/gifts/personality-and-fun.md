# 把个性，变成视觉签名

昵称、笑话、爱好、角色与圈子仪式，都能变成一眼就很个人的图案。

<a id="language-and-identity"></a>

## 把一句私人口头禅变成视觉暗号

一个准确昵称或共同笑话，能成为只属于懂它之人的紧凑视觉暗号。

一个准确昵称、口头禅或共同笑话，可以带领一张只有对的人才完全看懂的紧凑构图。熟悉话语成为设计的个性，又不暴露本应保留的私密内容。

## 把一份热爱变成个人徽章

[Circular Badge Layout](https://podplo.app/skills/circular-badge-layout) 把一个有意义的爱好、角色或星座线索，收成个人徽章。

## 让每个成员都属于同一视觉家族

4PC 与 [6PC Grid Generator](https://podplo.app/skills/six-piece-grid) 把一个共同图形发展成协调系列，同时让每个成员仍然有自己的区别。

一个共同图形能联系团队、社团或兴趣圈，每个姓名、角色、颜色或编号则让一位成员拥有独立位置。4PC 与 [6PC Grid Generator](https://podplo.app/skills/six-piece-grid) 让整组设计彼此相连，却不必每件都一模一样。
