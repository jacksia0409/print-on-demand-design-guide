# 素材类型

从一个独立元素，到一张完整图片，不同素材适合不同的创作方式。先认识 Elements 与 Images，再为它们找到合适的排版、主题与 Skill。

<a id="elements"></a>

Elements

## 从一个元素开始

Elements 是已经分离出来的独立图形，适合参与文字排版、徽章、边框、纹样与系列设计。下面选出 30 个集合作为示例，并未展示全部素材。点击“查看更多”，进入 Elements 素材库继续探索。

## 从一张完整图片开始

Images 保留了完整画面关系，适合从现有构图继续创作。你可以围绕主体重新排版、加入准确文字、改变节日主题，或用 Photo to Art 类 Skill 探索新的视觉表达。

优先选择主体清楚、与预期主题相符，并且包含你希望继续保留的画面特征的图片。
