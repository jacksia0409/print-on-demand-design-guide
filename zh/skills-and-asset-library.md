# 让素材遇见更多可能

从自己的图片或素材库出发，用不同 Skill，为熟悉的素材找到意想不到的新表达。

<a id="skill"></a>

## 让一张照片走进新角色

[Royal Pet Portrait](https://podplo.app/skills/royal-pet-portrait) 保留宠物辨识度，同时让照片拥有新的角色故事。

[Royal Pet Portrait](https://podplo.app/skills/royal-pet-portrait) 能把熟悉的宠照变成带有皇家气场的角色肖像。服饰与场景可以大幅变化，脸型、毛色花纹与神情仍让它一眼可认。

## 让你自己的素材库成为下一个灵感起点

保存你自己的素材，试试更多 Skill，把同一素材变成更多图案，用于更多产品。

保存自己的原始素材和喜欢的生成结果，下次从素材库中选一张，试试不同的 Skill：重新排版、变成连续纹样，或加入节日元素，让同一素材衍生出适合 T恤、马克杯、抱枕等产品的新图案。

## 灵感再来时，快速找回对的素材

好标签能让旧作品被重新找到，再通过 [Make It Christmas](https://podplo.app/skills/make-it-christmas) 开出新的节日版本。

用主体、节日、版式、颜色与来源等简单标签，旧灵感也能很快被重新找到。一张宠物肖像只要找得回来，就能通过 [Make It Christmas](https://podplo.app/skills/make-it-christmas) 衍生圣诞版本，同时保留同一只宠物的特征。

## 保留好结构，换一个新故事

[Dinosaur Name Pattern](https://podplo.app/skills/dinosaur-name-pattern) 让一个好版式随每个准确姓名生长成新的定制图案。

一个已经成立的构图，可以换入新姓名、新主体或新颜色，却不必变成简单复制。[Dinosaur Name Pattern](https://podplo.app/skills/dinosaur-name-pattern) 保留俏皮的重复结构，每个准确姓名都会带来自己的节奏。
