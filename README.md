## How to use it

1. Start with a subject, image, or design idea.
2. Browse the artwork types and compare compositions, lettering, and visual treatments.
3. Adapt a public creative direction to your image or prompt.
4. Follow the relevant PodPlo link to continue creating.

The guide includes **1,388 visual forms in 128 groups**, **123 public creative directions**, and **165 guide pages per language**. English and Simplified Chinese editions cover the same guide structure.

The diagrams explain visual ideas. They are conceptual studies, not a claim that every direction has been individually tested with image models. Check generated wording, transparent edges, and pattern continuity.
