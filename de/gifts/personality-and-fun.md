# Persönlichkeit und Spaß

Erstellen Sie persönliche Designs aus Spitznamen, Insider-Witzen, Hobbys, Rollen und Gruppentraditionen.

<a id="language-and-identity"></a>

## Gestalten Sie ein Design rund um einen Insiderwitz

Ein Spitzname oder ein gemeinsamer Witz können ein kompaktes, sehr persönliches Design verankern.

Ein Spitzname, ein Schlagwort oder ein gemeinsamer Witz können zu einem kompakten Design führen, das für die Zielgruppe sinnvoll ist. Verwenden Sie die vertraute Formulierung, ohne private Details anzugeben, die vertraulich bleiben sollten.

## Bauen Sie ein Symbol rund um ein persönliches Interesse auf

[Kreisförmiges Abzeichen-Layout](https://podplo.app/skills/circular-badge-layout) verwandelt ein Hobby, eine Rolle oder ein Sternzeichen in ein persönliches Emblem.

Wählen Sie ein bestimmtes Symbol aus einem Hobby, Beruf, einer Rolle oder einem Sternzeichenthema für ein [Kreisförmiges Abzeichen-Layout](https://podplo.app/skills/circular-badge-layout). Ein klares Etikett und ein aussagekräftiger visueller Hinweis schaffen ein persönliches Emblem, ohne sich auf Stereotypen zu verlassen.

## Bauen Sie ein koordiniertes Gruppenset auf

4PC und [6PC-Gittergenerator](https://podplo.app/skills/six-piece-grid) Verwandeln Sie ein gemeinsames Motiv in ein koordiniertes Set mit unterschiedlichen Variationen.

Verwenden Sie ein gemeinsames Motiv für ein Team, einen Club oder eine Community und variieren Sie dann den Namen, die Rolle, die Farbe oder die Nummer für jedes Mitglied. 4PC und [6PC-Gittergenerator](https://podplo.app/skills/six-piece-grid) Halten Sie das Set aufeinander abgestimmt, ohne dass jedes Design identisch ist.
