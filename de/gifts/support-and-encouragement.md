# Unterstützung und Ermutigung

Verwenden Sie ein bekanntes Foto oder eine kurze persönliche Nachricht, um ein durchdachtes Design für einen schwierigen Moment oder einen Neuanfang zu erstellen.

<a id="courage"></a>

## Gestalten Sie das Design um einen ermutigenden Satz

[Kompaktes Center-Layout](https://podplo.app/skills/compact-center-layout) verleiht einem ermutigenden kurzen Satz eine klare, beständige Präsenz.

Verwenden Sie einen Satz, den der Empfänger bereits für eine Prüfung, eine Herausforderung oder einen Neuanfang schätzt. [Kompaktes Center-Layout](https://podplo.app/skills/compact-center-layout) gibt der Textzeile eine klare, ruhige Präsenz, ohne daraus ein Versprechen über den Ausgang zu machen.

## Erstellen Sie eine einfache Unterstützungsbotschaft

Ein bekanntes Foto und eine kurze Nachricht können ein persönliches, unterstützendes Design schaffen.

Ein vertrautes Foto, eine sanfte Farbpalette oder eine kurze Kundennachricht können ein unterstützendes Design für die Genesung oder eine schwierige Zeit ergeben. Es soll Zuwendung ausdrücken, ohne medizinische Versprechungen zu machen.

## Kombinieren Sie einen Namen mit einer ehrlichen Botschaft

[Floraler Namensrahmen](https://podplo.app/skills/floral-name-frame) verbindet einen Namen mit einer direkten, persönlichen Botschaft.

Ein Name und eine direkte Anrede wie „Ich denke an Dich“ können zu einem persönlichen Blumenmuster werden. [Floraler Namensrahmen](https://podplo.app/skills/floral-name-frame) Präsentiert die Nachricht mit Bedacht, ohne zu versuchen, die dahinter stehende Konversation zu ersetzen.
