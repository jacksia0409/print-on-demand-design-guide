# Radiales Ornament

Dekorative Einheiten wiederholen sich um ein Zentrum und bilden ein endliches kreisförmiges Design.

<a id="understand"></a>

![Radiales Ornament: Dekorative Einheiten wiederholen sich um ein Zentrum, um ein endliches kreisförmiges Design zu bilden.](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/legacy-bounded--pattern-radial-1.svg)

## Was definiert diese Richtung?

Das wiederholte Ornament steht im Mittelpunkt. Eigenständig ausdrucksstarke Objekte in einer kreisförmigen Anordnung entsprechen eher einer radialen Motivgruppe.

## Setzen Sie diese Gestaltungsrichtung mit KI um.

Verwenden Sie dies mit einem Bild oder bitten Sie eine KI, Ihren Bild-Prompt in dieser Gestaltungsrichtung neu zu formulieren.

**Gestaltungsrichtung**

Muster → Endliche Muster → Radiales Ornament

**Eingabe und Ausgabe**

Wenn ein Bild vorliegt, passen Sie es an diese Gestaltungsrichtung an. Wenn ein Prompt vorliegt, formulieren Sie daraus einen vollständigen Prompt für die Bilderzeugung.

**Zielaufbau**

Wiederholen Sie verwandte Motive um ein Zentrum herum in einer klaren Winkel-, Richtungs- oder Schichtreihenfolge. Koordinieren Sie die innere und äußere Dichte, um ein vollständiges dekoratives Ornament zu bilden.

**Hintergrund**

Orientieren Sie sich an Inhalt, visueller Gestaltung und Farbpalette des vorhandenen Hintergrunds und passen Sie diese an den Zielaufbau an. Fehlt ein Hintergrund oder ist er lediglich einfarbig oder transparent, gestalten Sie einen thematisch passenden Hintergrund. Eine ausdrückliche Vorgabe für einen einfarbigen, transparenten oder anderen Hintergrund hat Vorrang.

**Textinhalt**

Behalten Sie eindeutig lesbare Wörter aus der Vorlage und deren Sprache bei und passen Sie ihre Darstellung an. Behaupten Sie nicht, unleserlichen Text rekonstruiert zu haben. Wenn kein Text vorgegeben ist, ergänzen Sie eine kurze passende Formulierung als Begleittext, ohne Hauptmotive, Handlung oder Aufbau zu verdecken. Ordnen Sie vorhandenen Text in die gewünschte Hierarchie ein und beachten Sie eine ausdrückliche Vorgabe, keinen Text hinzuzufügen.

**Beibehalten und anpassen**

Erhalten Sie das Kernthema und die wiedererkennbaren Merkmale. Nutzen Sie die visuelle Gestaltung und Farbpalette der Vorlage als Ausgangspunkt und ändern Sie diese nur, soweit die gewählte Richtung es erfordert. Beschreiben Sie neu hinzugefügte Inhalte nicht so, als wären sie bereits in der Vorlage vorhanden. Benennen Sie einen Konflikt zwischen ausdrücklichen Eingabevorgaben und notwendigen Zielbedingungen, statt zu behaupten, beide seien erfüllt.

**Umfang und Grenzen**

Das wiederholte Ornament steht im Mittelpunkt. Eigenständig ausdrucksstarke Objekte in einer kreisförmigen Anordnung entsprechen eher einer radialen Motivgruppe.
