# Lokales Texturfragment

Ein strukturierter Bereich nimmt einen Teil des Bildes ein und lässt einen anderen Grund sichtbar.

## Nehmen Sie diese Richtung in Richtung KI

Verwenden Sie es mit einem Bild oder bitten Sie die KI, Ihre Bildaufforderung in diese Richtung umzuschreiben.

**Gestaltungsrichtung**

Texturen → Zusammensetzung → Lokales Texturfragment

**Eingabe und Ausgabe**

Wenn ein Bild vorliegt, passen Sie es an diese Gestaltungsrichtung an. Wenn ein Prompt vorliegt, formulieren Sie daraus einen vollständigen Prompt für die Bilderzeugung.

**Zielaufbau**

Konzentrieren Sie relevante Oberflächendetails innerhalb eines lokalisierten Flecks mit einer regelmäßigen, natürlichen oder verblassenden Grenze. Halten Sie den umliegenden Raum für Hintergrundinformationen oder unterstützende Informationen frei.

**Hintergrund**

Referenzmaterial, Farbpalette und Atmosphäre, um bei Fehlen eine relevante Oberflächenbehandlung zu schaffen. Ein lokaler Patch kann eine separate Unterstützung haben; eine vollflächige Textur verschmilzt mit dem Untergrund. Vermeiden Sie das Hinzufügen eines dominanten Objekts oder einer narrativen Umgebung.

**Textinhalt**

Behalten Sie eindeutig lesbare Wörter aus der Vorlage und deren Sprache bei und passen Sie ihre Darstellung an. Behaupten Sie nicht, unleserlichen Text rekonstruiert zu haben. Wenn kein Text vorgegeben ist, ergänzen Sie eine kurze passende Formulierung als Begleittext, ohne Hauptmotive, Handlung oder Aufbau zu verdecken. Ordnen Sie vorhandenen Text in die gewünschte Hierarchie ein und beachten Sie eine ausdrückliche Vorgabe, keinen Text hinzuzufügen.

**Beibehalten und anpassen**

Behalten Sie relevantes Material, Oberfläche, Farbpalette und Atmosphäre bei, ohne dass eine Objektsilhouette oder eine vollständige Szene erforderlich ist. Erzielen Sie den gewünschten Effekt, wenn materielle Hinweise fehlen, ohne den Anspruch zu erheben, das tatsächliche Material der Quelle identifiziert zu haben. Beschreiben Sie neu erstellte Inhalte nicht als in der Quelle vorhanden. Geben Sie einen Konflikt zwischen expliziten Eingabebeschränkungen und notwendigen Zielbedingungen an, anstatt zu behaupten, dass beide erfüllt seien.

**Umfang und Grenzen**

Die Textur bleibt der Hauptinhalt. Wenn der Patch zu einem identifizierbaren Objekt wird, dessen Identität dominiert, betrachten Sie ihn erneut als Subjektkunstwerk.
