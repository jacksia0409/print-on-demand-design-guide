# Leinwand- und gerahmte Drucke

Verwandeln Sie eine Lieblingsillustration oder ein Lieblingsfoto in ein Leinwandkunstwerk für zu Hause.

<a id="product-overview"></a>

## Designideen für dieses Produkt

### Geben Sie einem Lieblingsbild eine eigene Wand

Verwenden Sie ein Familienporträt, eine weite Landschaft oder ein klares Motiv, um eine Leinwand zu erstellen, die zum Raum passt. Ein vielschichtiges Familienporträt; Eine weite Landschaft; Ein klares Motiv auf einem einfachen Hintergrund.

## Sehen Sie sich das Design auf dem Produkt in der Vorschau an

### Sehen Sie sich die Leinwand an der Wand in der Vorschau an

Die KI-Vorschau platziert das Porträt, die Landschaft oder die Grafik in einem Raum, damit Sie die Kompositionen vergleichen können.

- Ein Porträt aus nächster Nähe sorgt dafür, dass die Menschen im Vordergrund stehen

- Eine weite Landschaft füllt einen größeren Teil der Wand aus

- Ein einfacher Hintergrund lenkt die Aufmerksamkeit auf das Motiv
