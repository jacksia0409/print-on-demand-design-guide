# Tassen

Nutzen Sie die gesamte Tasse: ein Bild auf einer Seite, ein Spruch auf der anderen oder ein umlaufender Rapport.

<a id="product-overview"></a>

## Designideen für dieses Produkt

### Design über die Front hinaus

Eine Tasse kann Bilder und Wörter auf zwei Seiten kombinieren oder ein durchgehendes Design rund um die Tasse tragen. Ein Porträt gepaart mit einem kurzen Satz; Verwandte Grafiken auf gegenüberliegenden Seiten; Ein sich wiederholendes Muster rund um die Tasse.

## Sehen Sie sich das Design auf dem Produkt in der Vorschau an

### Vorschau des vollständig umlaufenden Designs

Die KI-Vorschau zeigt, wie das Bild, die Phrase oder das Muster auf der Vorder- und Rückseite sowie im Raum um den Griff herum erscheint.

- Verwenden Sie eine Seite für das Bild und die andere für die Nachricht

- Überprüfen Sie, wie sich der Rapport rund um die Tasse verbindet

- Verwenden Sie die Tassenfarbe als Teil der Palette
