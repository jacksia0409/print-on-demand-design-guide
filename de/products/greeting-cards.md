# Grußkarten und Einladungen

Erstellen Sie eine Grußkarte mit einer Illustration, einer kurzen Nachricht oder einem personalisierten Namen und Datum.

<a id="product-overview"></a>

## Designideen für dieses Produkt

### Design für einen bestimmten Anlass

Die Vorderseite der Karte kann mit dem Bild, der Botschaft oder einer ausgewogenen Kombination aus beidem versehen sein. Eine warme Illustration mit einer einfachen Botschaft; Ein verspieltes Bild, das um einen Witz herum aufgebaut ist; Ein Name oder ein Datum, das dem Anlass hinzugefügt wurde.

## Sehen Sie sich das Design auf dem Produkt in der Vorschau an

### Vorschau der fertigen Kartenvorderseite

Nutzen Sie die KI-Vorschau, um ein verspieltes, persönliches oder feierliches Kartendesign zu vergleichen.

- Konzentrieren Sie die Karte auf eine klare Botschaft

- Ein Name macht einen vertrauten Anlass persönlich

- Verwenden Sie das Bild und den Wortlaut, um dieselbe Idee zu unterstützen
