## Wählen Sie, was das Bild leitet

Ein hervorgehobenes Motiv kann vor einem gemusterten Hintergrund stehen und dennoch die Gestaltung bestimmen. Erkennbare geometrische oder stilisierte Motive gehören ebenfalls zu dieser Kategorie; nichtgegenständliche Kompositionen gehören zur Abstraktion. Entdecken Sie unten Text, Schriftgestaltung und Hintergrunddesign für alle fünf Gestaltungsformen.

### Rollen von Text und Motiv

<a id="text-role-group-word-g20"></a>

Vergleichen Sie die dem Text zugewiesene visuelle Rolle, von Beschriftungen und Sprache bis hin zu Ton, Abzeichen, Titelbildern, Hintergründen, Akzenten und Co-Leads.

<a id="form-lettering-20-0"></a>

![Identifikationsetikett – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-20-0.svg)

<a id="form-lettering-20-2"></a>

![Sprechblase – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-20-2.svg)

##### Sprechblase

Setzen Sie die gesprochenen Worte der Figur in eine sichtbare Sprechblase.

<a id="form-lettering-20-4"></a>

![Lautmalerische Schriftgestaltung — visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-20-4.svg)

##### Lautmalerische Schriftgestaltung

Umgeben Sie das Motiv mit schriftlichen Soundeffekten für Schnurren, Brüllen, Stöße oder andere Geräusche.

<a id="form-lettering-20-5"></a>

![Abzeichenkombination – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-20-5.svg)

##### Abzeichenkombination

Kombinieren Sie Text und Bilder zu einem Abzeichen-, Siegel-, Wappen- oder Teamemblem-Design.

<a id="form-lettering-20-6"></a>

![Überschrift und Illustration – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-20-6.svg)

##### Überschrift und Illustration

Lassen Sie den Text das Thema benennen, während das Motiv es illustriert.

<a id="form-lettering-20-7"></a>

![Texthintergrundwand – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-20-7.svg)

##### Texthintergrundwand

Wiederholen Sie gedämpfte Wörter oder Sätze hinter dem Motiv und behalten Sie dabei das Bild im Mittelpunkt.

<a id="form-lettering-20-8"></a>

![Kleines Motiv in großer Schrift – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-20-8.svg)

##### Kleines Motiv in großer Schrift

![Gleichwertige Hauptrollen für Text und Bild – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-20-9.svg)

##### Gleichwertige Hauptrollen für Text und Bild

Geben Sie Text und abgebildetem Motiv das gleiche visuelle Gewicht, damit sie die Botschaft gemeinsam vermitteln.

### Semantische Beziehungen zwischen Text und Motiv

<a id="text-meaning-group-word-g21"></a>

Vergleichen Sie, wie Formulierungen durch Benennung, Identität, Einstellung, Emotionen, Geschichte, Humor, Wortspiele, Rebus-Logik, Personalisierung oder Serienkontinuität mit Bildern zusammenhängen.

<a id="form-lettering-21-0"></a>

![Direkte Benennung – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-0.svg)

##### Direkte Benennung

Ordnen Sie dem abgebildeten Motiv den entsprechenden Namen zu, beispielsweise eine Katze neben dem Namen der Katze.

<a id="form-lettering-21-1"></a>

![Identitätserklärung – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-1.svg)

##### Identitätserklärung

Kennzeichnen Sie das Motiv durch einen Beruf, ein Interesse, einen Ort, eine Gemeinschaft oder eine Figurenrolle.

<a id="form-lettering-21-2"></a>

![Ausdruck einer Haltung – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-2.svg)

##### Ausdruck einer Haltung

Lassen Sie das Bild eine Persona etablieren, während der Wortlaut seine Einstellung oder Lebensweise zum Ausdruck bringt.

<a id="form-lettering-21-3"></a>

![Emotionale Verstärkung – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-3.svg)

##### Emotionale Verstärkung

Verwenden Sie sowohl das Bild als auch einen kurzen Satz, um dieselbe Emotion zu verstärken.

<a id="form-lettering-21-4"></a>

![Story-Erweiterung – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-4.svg)

##### Story-Erweiterung

Fügen Sie eine Formulierung hinzu, die die Zeit, den Ort, den Grund oder die Erfahrung hinter dem abgebildeten Moment angibt.

<a id="form-lettering-21-5"></a>

![Humorvoller Kontrast – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-5.svg)

##### Humorvoller Kontrast

Erzeugen Sie Humor, indem Sie ein niedliches Motiv mit einer harten Aussage oder ein ernstes Motiv mit einem lockeren Kommentar kombinieren.

<a id="form-lettering-21-6"></a>

![Wortspiel – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-6.svg)

##### Wortspiel

Lassen Sie das abgebildete Motiv an einem Wortspiel, einem Homophon oder einem Witz teilhaben, der auf einer wörtlichen Formulierung basiert.

<a id="form-lettering-21-7"></a>

![Text-Bild-Puzzle – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-7.svg)

##### Text-Bild-Puzzle

Lassen Sie Bild und Wortlaut jeweils Informationen liefern, die nur in Kombination Sinn ergeben.

<a id="form-lettering-21-8"></a>

![Persönliches Gedenken – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-8.svg)

##### Persönliches Gedenken

Fügen Sie einen persönlichen Namen, ein Datum, Koordinaten, einen Gedenksatz oder eine spezielle Anrede hinzu.

<a id="form-lettering-21-9"></a>

![Koordinierte Serie – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/lettering-21-9.svg)

##### Aufeinander abgestimmte Serie

Ordnen Sie verschiedenen Motiven unterschiedliche Wörter zu, um eine abgestimmte Familien-, Paar- oder Teamserie zu gestalten.

![Postimpressionismus – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-48-1.svg)

#### Postimpressionismus

Verschieben Sie beobachtete Farben und Strukturen in eine persönlichere, symbolische oder geometrische Organisation, die über den optischen Eindruck hinausgeht.

<a id="form-art-48-2"></a>

![Fauvismus – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-48-2.svg)

#### Fauvismus

Verwenden Sie intensive, unnatürliche Farben und vereinfachte Formen, um dem Farbton selbst eine emotionale Kraft zu verleihen.

<a id="form-art-48-3"></a>

![Expressionismus – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-48-3.svg)

#### Expressionismus

Verzerren Sie Farbe, Anatomie und Raum, sodass innere Spannung wichtiger wird als äußere Genauigkeit.

<a id="form-art-48-4"></a>

![Kubismus – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-48-4.svg)

#### Kubismus

Fragmentieren Sie Motive in ineinandergreifende Ebenen und simultane Blickwinkel und bauen Sie Volumen auf einem flachen Bildfeld wieder auf.

<a id="form-art-48-5"></a>

![Futurismus – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-48-5.svg)

#### Futurismus

Multiplizieren Sie Diagonalen, Geschwindigkeitslinien und wiederholte Formen, um Beschleunigung, Maschinerie und moderne urbane Bewegung zu feiern.

<a id="form-art-48-6"></a>

![Dada – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-48-6.svg)

#### Dada

Kombinieren Sie absurde Objekte, Anti-Kunst-Gesten, Zufall und typografische Störungen, um konventionelle Bedeutungen zu untergraben.

<a id="form-art-48-7"></a>

![Surrealismus – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-48-7.svg)

#### Surrealismus

Platzieren Sie überzeugend wiedergegebene Objekte in traumhaften Beziehungen, in denen Maßstab, Physik und Erzähllogik nicht mehr gelten.

<a id="form-art-48-8"></a>

![Abstrakter Expressionismus – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-48-8.svg)

#### Abstrakter Expressionismus

Verwenden Sie spontane Striche, Tropfen und körperliche Gesten, damit der Akt des Malens das dominierende Thema bleibt.

<a id="form-art-48-9"></a>

![Farbfeldmalerei – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-48-9.svg)

#### Farbfeldmalerei

Verteilen Sie große, ruhige Farbflächen über das Bild und lassen Sie subtile Grenzen zu, um einen immersiven emotionalen Raum zu schaffen.

<a id="form-art-48-10"></a>

![Pop Art – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-48-10.svg)

#### Pop-Art

Verleihen Sie den Symbolen der Massenmedien kräftige, flache Farben, wiederholten Bildern und einer bewusst kommerziellen grafischen Sprache.

<a id="form-art-48-11"></a>

![Op Art – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-48-11.svg)

#### Op-Art

Erzeugen Sie optische Schwingungen durch wiederholte kontrastreiche Geometrie, Interferenzmuster und instabile Figur-Grund-Beziehungen.

<a id="form-art-48-12"></a>

![Minimalismus – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-48-12.svg)

#### Minimalismus

Reduzieren Sie die Komposition auf wenige exakte Elemente und betonen Sie dabei Proportionen, Wiederholungen, materielle Klarheit und bewusste Zurückhaltung.

<a id="form-art-48-13"></a>

![Präzisionismus – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-48-13.svg)

#### Präzisionismus

Stellen Sie Fabriken, Türme und Maschinen mit klarer Geometrie, glatten Oberflächen und einer kontrollierten, modernen, monumentalen Ruhe dar.

### Abstrakte und geometrische Stile

Vergleichen Sie abstrakte Systeme nach geometrischem oder organischem Vokabular, Kantenkontrolle, Kompositionsregel, Spontaneität, Dichte und generativem Verfahren.

<a id="form-art-49-0"></a>

#### Biomorphe Abstraktion

Verwenden Sie zellartige Silhouetten und lebende Konturen, die an Körper oder Organismen erinnern, ohne eine bestimmte Art darzustellen.

<a id="form-art-49-3"></a>

![Hard-Edge-Malerei – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-49-3.svg)

#### Hard-Edge-Malerei

Trennen Sie flache Farbbereiche mit makellos scharfen Kanten und eliminieren Sie so die sichtbare Weichheit des Pinsels zwischen benachbarten Formen.

<a id="form-art-49-4"></a>

![Rasterkomposition – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-49-4.svg)

#### Rasterkomposition

Verankern Sie Elemente in wiederholten horizontalen und vertikalen Unterteilungen, sodass Ausrichtung und Intervall im Mittelpunkt der Komposition stehen.

<a id="form-art-49-5"></a>

![Modulare Komposition – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-49-5.svg)

#### Modulare Komposition

Kombinieren Sie standardisierte visuelle Einheiten zu größeren Systemen, die erweitert, neu angeordnet oder wiederholt werden können, ohne die Kohärenz zu verlieren.

<a id="form-art-49-6"></a>

![Dynamische Komposition – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-49-6.svg)

#### Dynamische Komposition

Erzeugen Sie Kraft durch Diagonalen, Ungleichgewicht, Richtungskurven und ungleichmäßiges visuelles Gewicht statt durch stabile Symmetrie.

<a id="form-art-49-7"></a>

![Flüssige Abstraktion – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-49-7.svg)

#### Flüssige Abstraktion

Lassen Sie gegossene oder marmorierte Farbe in verzweigte Strömungen, weiche Grenzen und natürlich entstehende Farbansammlungen fließen.

<a id="form-art-49-8"></a>

![Automatisches Zeichnen – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-49-8.svg)

#### Automatisches Zeichnen

Folgen Sie kontinuierlichen instinktiven Zeichen ohne ein geplantes Thema, sodass im Nachhinein unbewusste Assoziationen entstehen.

<a id="form-art-49-9"></a>

![Maximalistische Abstraktion – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-49-9.svg)

#### Maximalistische Abstraktion

Überlagern Sie üppige Farben, Motive und Texturen, bis Dichte, Kollision und visueller Überschuss zum Haupteffekt werden.

<a id="form-art-49-10"></a>

![Parametrische Grafiken – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-49-10.svg)

#### Parametrische Grafiken

Verwenden Sie anpassbare geometrische Regeln, um Familien präziser Formen zu generieren, die sich in der Komposition gleichmäßig ändern.

<a id="form-art-49-11"></a>

![Algorithmische Kunst – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-49-11.svg)

#### Algorithmische Kunst

Bestimmen Sie die Form durch explizite Verfahren, Wiederholungen und kalkulierte Variationen und nicht durch direkte intuitive Platzierung.

### Straßen- und Independent-Publishing

#### Graffiti

Erstellen Sie Buchstaben aus großen Sprühbewegungen, geschichteten Umrissen, Tropfen und Farbfüllungen, die an öffentliche Wände angepasst sind.

Verwenden Sie schnell geschnittene Masken, scharfes Overspray und wiederholte kontrastreiche Symbole, die für die unerlaubte Platzierung auf der Straße geeignet sind.

#### Punk-Collage

Kombinieren Sie ausgeschnittene Buchstabenschrift im Erpresserbriefstil, gerissene Fotos, Klebeband und aggressive Slogans zu einer bewusst instabilen Komposition.

#### Grunge

Kombinieren Sie erodierte Texturen, schmutzige Neutraltöne, grobe Typografie und abgenutzte Fotofragmente zu einer dichten, abgenutzten Oberfläche.

Ordnen Sie isolierte Motive als gestochen scharfe Flash-Designs mit kräftigen Umrissen, begrenzter Schattierung und Platz um jedes Emblem herum an.

Bewahren Sie Tonerkörnung, zugelaufene Schwarztöne, wiederholten Qualitätsverlust und schiefe Ränder aus aufeinanderfolgenden Fotokopien.

Füllen Sie offene Bereiche mit spontanen Wörtern, Gesichtern, Pfeilen und winzigen Markierungen, die ohne formelle Planung gezeichnet wurden.

### Fantasie und Zukunft

Vergleichen Sie imaginäre Welten anhand ihres Erzähltons, ihrer Technologie, Architektur, Ökologie und Beziehung zwischen organischem Leben und Maschinerie.

<a id="form-art-54-0"></a>

![Märchenfantasie – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-54-0.svg)

#### Märchenhafte Fantasie

Platzieren Sie archetypische Charaktere, verzauberte Natur und sanfte Unmöglichkeiten in einer klaren Bilderbuchwelt.

<a id="form-art-54-1"></a>

![Dunkles Märchen – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-54-1.svg)

#### Dunkles Märchen

Verdrehen Sie vertraute Folklore durch bedrohliche Wälder, beunruhigende Unschuld und Konsequenzen, die sich emotional gefährlich anfühlen.

<a id="form-art-54-2"></a>

![Gothic Fantasy – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-54-2.svg)

#### Gothic-Fantasie

Kombinieren Sie spitze Architektur, mondbeschienene Ruinen, kunstvolle Dunkelheit und verletzliche Gestalten mit übernatürlichem Schrecken.

<a id="form-art-54-3"></a>

![Kosmische Fantasie – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-54-3.svg)

#### Kosmische Fantasie

Inszenieren Sie mythische Wesen vor riesigen Sternen, Nebeln und unbegreiflichen Strukturen, die den gewöhnlichen menschlichen Maßstab weit überragen.

<a id="form-art-54-4"></a>

![Retro-Science-Fiction – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-54-4.svg)

#### Retro-Science-Fiction

Stellen Sie sich das Morgen mit analogen Steuerungen, bemalten Raumschiffen, auffälligen Uniformen und den optimistischen Grenzen einer früheren Ära vor.

<a id="form-art-54-5"></a>

![Weltraumzeitalter – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-54-5.svg)

#### Weltraumzeitalter

Nutzen Sie stromlinienförmige Raketen, Orbitalringe, Sternenexplosionen und lebhafte Visionen der Raumfahrt aus der Atomzeit.

<a id="form-art-54-6"></a>

![Cyberpunk – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-54-6.svg)

#### Cyberpunk

Kontrastieren Sie Neoninformationen, dichte Megastädte, Körpertechnologie und sozialen Verfall unter der Macht der Konzerne.

<a id="form-art-54-7"></a>

![Steampunk – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-54-7.svg)

#### Steampunk

Steuern Sie fortschrittliche Maschinen mit Messing, Nieten, Messgeräten und aufwendigen Mechanismen aus dem Dampfzeitalter.

<a id="form-art-54-8"></a>

![Dieselpunk – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-54-8.svg)

#### Dieselpunk

Gestalten Sie schwere retrofuturistische Welten mit Dieselmotoren, gepanzerten Maschinen, Rauch und Industriedesign der Zwischenkriegszeit.

<a id="form-art-54-9"></a>

![Solarpunk – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-54-9.svg)

#### Solarpunk

Stellen Sie sich üppige grüne Städte vor, in denen erneuerbare Technologie, Gemeinschaftsleben und natürliches Wachstum sichtbar nebeneinander existieren.

<a id="form-art-54-10"></a>

![Biomechanisch – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-54-10.svg)

#### Biomechanisch

Verschränken Sie Muskeln, Knochen, Kabel und künstliche Schalen, bis Organismus und Maschine eine beunruhigende Anatomie bilden.

<a id="form-art-54-11"></a>

![Außerirdische Ökologie – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-54-11.svg)

#### Außerirdische Ökologie

Entwerfen Sie unbekannte Ökosysteme durch kohärente Nahrungsketten, Anatomie, Lebensräume und Umweltanpassungen statt durch zufällige Monster.

### Stimmung und Sensibilität

Vergleichen Sie die allgemeinen Sensibilitäten, die sich durch Politur, Dichte, Sanftheit, Zurückhaltung, Humor, Dunkelheit, Monumentalität und Einstellungen zur Natur ausdrücken.

<a id="form-art-55-0"></a>

![Naiv und ungeschliffen – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-55-0.svg)

#### Naiv und ungeschliffen

Achten Sie auf unkonventionelle Markierungen, ungeübte Proportionen und sichtbar aufrichtige Entscheidungen, um dem Bild direkte emotionale Offenheit zu verleihen.

<a id="form-art-55-1"></a>

![Verspielt und niedlich – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-55-1.svg)

#### Verspielt und süß

Verwenden Sie beschwingte Formen, leuchtende Farben, sanfte Gesichtsausdrücke und kleine visuelle Überraschungen, die Zuneigung wecken.

<a id="form-art-55-2"></a>

![Grotesker Humor – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-55-2.svg)

#### Grotesker Humor

Kombinieren Sie körperliche Verzerrungen oder beunruhigende Details mit komischem Timing, damit Unbehagen seltsam komisch wird.

<a id="form-art-55-3"></a>

![Absurder Surrealismus – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-55-3.svg)

#### Absurder Surrealismus

Behandeln Sie unmögliche Ereignisse als gewöhnlich und nutzen Sie ausdruckslose Gegenüberstellungen und irrationale Ursache-Wirkungs-Verhältnisse für Humor oder Unbehagen.

<a id="form-art-55-4"></a>

![Verträumte Weichheit – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-55-4.svg)

#### Verträumte Weichheit

Mildern Sie Kontraste und Kanten mit blassen Farben, Trübungen und schwebenden Details, die sich halb erinnert anfühlen.

<a id="form-art-55-5"></a>

![Coole Zurückhaltung – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-55-5.svg)

#### Coole Zurückhaltung

Begrenzen Sie Gesten, Farben und Ornamente, sodass emotionale Distanz und genaue Kontrolle das Bild prägen.

<a id="form-art-55-6"></a>

![Roh und robust – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-55-6.svg)

#### Roh und robust

Machen Sie grobe Texturen, stumpfe Formen, Kratzer und physisches Gewicht sichtbar, ohne ihre Härte zu glätten.

<a id="form-art-55-7"></a>

![Reichhaltige Verzierung – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-55-7.svg)

#### Reichhaltige Verzierung

Überlagern Sie Ränder, Muster, Schnörkel und dekorative Oberflächen, bis die Komposition üppig und voll wirkt.

<a id="form-art-55-8"></a>

![Romantische Sanftheit – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-55-8.svg)

#### Romantische Weichheit

Nutzen Sie zarte Gesten, leuchtende Farben, anmutige Kurven und eine sanfte Atmosphäre, um Intimität und Sehnsucht zu steigern.

<a id="form-art-55-9"></a>

![Dunkles Geheimnis – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-55-9.svg)

#### Dunkles Geheimnis

Umgeben Sie teilweise freigelegte Motive mit tiefen Schatten, gedämpften Farben und ungelösten narrativen Hinweisen.

<a id="form-art-55-10"></a>

![Luftige Leichtigkeit – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-55-10.svg)

#### Luftige Leichtigkeit

Bevorzugen Sie helle Werte, offene Abstände, dünne Formen und Aufwärtsbewegungen, damit die Komposition kaum zu wiegen scheint.

<a id="form-art-55-11"></a>

![Feierliches Gedenken – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-55-11.svg)

#### Feierliche Gedenkfeier

Verwenden Sie stabile Symmetrie, zurückhaltende Farben, formale Symbole und maßvolle Abstände, um das kollektive Gedächtnis zu würdigen.

<a id="form-art-55-12"></a>

![Wilde Natur – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-55-12.svg)

#### Wilde Natur

Lassen Sie verworrenes Wachstum, räuberische Bewegungen, Wetter und ungezähmte Ausmaße die geordnete menschliche Struktur überwältigen.

<a id="form-art-55-13"></a>

![Industrielle Stärke – visuelle Studie](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/art-55-13.svg)

#### Industrielle Stärke

Betonen Sie massive Geometrie, dunkle Metalle, harte Kanten und wiederholte strukturelle Stützen, um technische Kraft zu vermitteln.
