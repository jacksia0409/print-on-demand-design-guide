# Verfeinern Sie Ihr Bild

Schärfen Sie Details, entfernen Sie einen Hintergrund oder erweitern Sie eine Szene. Holen Sie das Beste aus einem Bild heraus, das Sie bereits lieben.

<a id="pixels"></a>

## Bringen Sie feine Details zur Geltung

[HD-Upscale](https://podplo.app/skills/hd-upscale) Schärft Textur und kleine Details und bewahrt gleichzeitig die Komposition.

[HD-Upscale](https://podplo.app/skills/hd-upscale) kann feine Kanten, Texturen und kleine Formen in einem ausgewählten Bild schärfen. Es sorgt für Klarheit, ohne das Thema oder die Komposition zu ändern.

## Wiederverwendung eines Motivs vor neuen Hintergründen

[Hintergrundentferner](https://podplo.app/skills/background-remover) Isoliert ein Motiv, sodass es in verschiedenen Layouts und Szenen wiederverwendet werden kann.

[Hintergrundentferner](https://podplo.app/skills/background-remover) Isoliert ein Porträt, eine Blume oder ein Objekt, sodass es mit neuen Farben, Layouts und Szenen verwendet werden kann. Ein Foto wird zum wiederverwendbaren Gestaltungselement für mehrere Kompositionen.

## Erweitern Sie die Szene über den Rahmen hinaus

[Smart Outpaint](https://podplo.app/skills/smart-outpaint) Erweitert ein Foto zu einer breiteren, höheren oder geräumigeren Komposition.

[Smart Outpaint](https://podplo.app/skills/smart-outpaint) Fügt der Originalszene einen plausiblen Himmel, eine Landschaft, einen Innenraum oder eine Atmosphäre hinzu, ohne das Motiv zu strecken. Das gleiche Foto kann zu einer breiteren Komposition, zu einer höheren oder zu einem geräumigeren Hintergrund werden.

## Vergleichen Sie Ihre stärksten Varianten

Side-by-Side-Varianten erleichtern die Entscheidung, was als Nächstes entwickelt werden soll.

Behalten Sie das Original bei, abgesehen von ein paar starken Variationen. Der Vergleich nebeneinander erleichtert die Auswahl des besten Motivs, der besten Kopie oder der besten Komposition für die nächste Runde.
