# Machen Sie jedes Design persönlich

Erstellen Sie ein individuelles Design rund um einen Namen, ein besonderes Datum oder ein Lieblingsfoto. Kleine Details machen es persönlich.

<a id="variables"></a>

## Bauen Sie das Design auf persönliche Details auf

Namen, Daten, Fotos, Farben und kurze Nachrichten machen ein gemeinsames Layout persönlich.

Ein Name, ein Datum, eine Nummer, ein Foto, ein Haustier, eine Farbe oder eine kurze Nachricht können ein Design spezifisch für eine Person machen. Nutzen Sie die Angaben des Kunden, anstatt fehlende Informationen einzutragen.

## Verwenden Sie klare Fotos und bestätigte Details

Klare Fotos und bestätigte Details führen zu spezifischeren, glaubwürdigeren personalisierten Kunstwerken.

Ein schärferes Foto, ein vollständig sichtbares Gesicht, ein bestätigtes Datum oder eine kürzere Botschaft führen meist zu einem stärkeren Design. Fehlt eine persönliche Angabe, lassen Sie sie weg, statt sie vom Bild erfinden zu lassen.
