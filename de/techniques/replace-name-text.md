# Machen Sie es persönlich mit einem Namen oder einer Nachricht

Fügen Sie einen Namen, ein paar aussagekräftige Wörter oder ein besonderes Datum hinzu. Machen Sie den Text zu einem Teil des Designs.

[Floraler Namensrahmen](https://podplo.app/skills/floral-name-frame) platziert einen Namen wie ANDREA in einem ausgewogenen Aquarell-Blumendesign.

[Floraler Namensrahmen](https://podplo.app/skills/floral-name-frame) platziert einen Namen wie ANDREA in einem ausgewogenen Aquarell-Blumenrahmen. Der Abstand passt sich dem Namen an, sodass sich jedes Mal das gleiche Blumenkonzept individuell anfühlt.

## Bauen Sie das Design auf einer kurzen Phrase auf

[Titel-Betreff-Untertitel-Layout](https://podplo.app/skills/title-subject-subtitle-layout) baut eine klare, textgeführte Komposition rund um STAY WILD und ein Kunstwerk auf.

[Titel-Betreff-Untertitel-Layout](https://podplo.app/skills/title-subject-subtitle-layout) macht eine Zeile wie STAY WILD zur Überschrift und ordnet dann das Bildmaterial und eine optionale unterstützende Zeile darum herum an. Das Bild zeigt das Layout; es handelt sich nicht um eine automatische Textersetzung.

## Erstellen Sie ein Erinnerungsabzeichen

[Kreisförmiges Abzeichen-Layout](https://podplo.app/skills/circular-badge-layout) vereint ein Kunstwerk und ein Datum in einem kompakten Gedenkemblem.

[Kreisförmiges Abzeichen-Layout](https://podplo.app/skills/circular-badge-layout) Umschließt Text wie EST. 2024 oder 10.12.2024 um ein zentrales Kunstwerk, sodass das Datum Teil der Komposition wird. Das Bild zeigt die Struktur des Abzeichens. Es handelt sich nicht um eine automatische Datumsersetzung.
