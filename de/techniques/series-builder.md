# Verwandeln Sie eine Idee in eine Sammlung

Erstellen Sie ein aufeinander abgestimmtes vier- oder sechsteiliges Set mit einem anderen Design in jedem Panel. Achtteilige Exemplare stehen noch aus.

## 4PC: Vier Richtungen erkunden

[4PC-Gittergenerator](https://podplo.app/skills/four-piece-grid) entwickelt eine Referenz in vier aufeinander abgestimmte Designrichtungen.

[4PC-Gittergenerator](https://podplo.app/skills/four-piece-grid) entwickelt eine Referenz in vier verwandte, aber unterschiedliche Kompositionen. Das Thema bleibt konsistent, während sich das Layout, die unterstützenden Elemente und der Schwerpunkt von Panel zu Panel ändern.

[6PC-Gittergenerator](https://podplo.app/skills/six-piece-grid) erweitert eine Referenz in sechs koordinierte Richtungen. ## 8PC: Planen Sie die Sammlung

Planen Sie acht verschiedene Rollen rund um eine Palette; Das 8PC-Bild ist ein Platzhalter und kein unterstützter Generator.

Sie können ein achtteiliges Set planen, indem Sie jedem Panel eine Rolle, eine gemeinsame Palette und eine eigene Komposition zuweisen. Dieses Bild ist nur ein Planungsplatzhalter: PodPlo bietet derzeit 4PC und 6PC Skills, keinen 8PC-Generator.
