# Mantas

Escala un retrato, repite un patrón o un collage de fotos sobre una manta.

<a id="product-overview"></a>

## Ideas de diseño para este producto.

### Usa la manta completa

Elija una imagen de gran tamaño, una repetición completa o un collage que reúna varias fotografías en una sola composición. Un retrato grande; Una repetición completa; Un collage de fotografías relacionadas.

## Vista previa del diseño en el producto.

### Vista previa extendida y doblada

La vista previa de IA muestra cómo cambia un retrato, una repetición o un collage de gran tamaño cuando la manta se extiende, se dobla o se coloca en una habitación.

- Un sujeto grande crea un punto focal claro

- Una repetición cambia a medida que la manta se pliega.

- Un collage combina varias fotografías en un solo diseño.
