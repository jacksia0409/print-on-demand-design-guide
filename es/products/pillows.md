# Almohadas y cojines

Utilice el formato de almohada cuadrada para una imagen centrada, una frase corta o un patrón repetido.

<a id="product-overview"></a>

## Ideas de diseño para este producto.

### Organiza el diseño en torno al formato cuadrado

Los sujetos centrados, los diseños simétricos y las repeticiones equilibradas funcionan bien sobre una almohada. Un retrato centrado; Una frase corta utilizada como gráfico principal; Una repetición diseñada para coordinar con otras almohadas.

## Vista previa del diseño en el producto.

### Vista previa en un sofá o cama

Utilice la vista previa de IA para comparar una almohada llamativa con un diseño coordinado más simple.

- Un sujeto centrado crea un punto focal claro

- Una repetición facilita la construcción de un conjunto coordinado.

- Usa el color de fondo para conectar la almohada con la habitación.
