# Tipos de materiales de origen

Desde un elemento aislado hasta una imagen completa, diferentes fuentes invitan a diferentes tipos de creación. Explore elementos e imágenes y luego elija un diseño, tema o Skill que se adapte a sus necesidades.

Elementos

## Empezar con un elemento

Los elementos son gráficos aislados que pueden formar parte de un diseño tipográfico, insignia, marco, repetición o conjunto coordinado. Estas 30 colecciones son sólo una muestra. Seleccione "Ver más" para explorar la biblioteca completa de Elements.
