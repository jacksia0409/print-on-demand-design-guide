# Backpacks and lunch bags

Build a backpack design around one bold character, an all-over pattern, or a personalized name graphic.

<a id="product-overview"></a>

## Design ideas for this product

### Design for the whole backpack

Use the main panel for the focal image, then repeat colors or symbols across the rest of the design. One character on the main panel; An all-over repeat; A name built into the illustration.
