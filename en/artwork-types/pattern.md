# Patterns

Motifs create a decorative whole through repetition or a clear arrangement. A seamless repeat needs its own edge check.

## Pattern composition and treatments

<a id="pattern"></a>

VISUAL FORMS · 66

### Pattern elements and composition

<a id="pattern-panel-word-g59-pattern"></a>

<a id="pattern-group-word-g59-pattern"></a>

#### Direction and motion paths

Compare how motif orientation follows one-way, alternating, rotating, radial, curved, or directional movement within a designed field.

<a id="form-pattern-59-0"></a>

![One-way orientation — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-0.svg)

##### One-way orientation

Keep every unit facing the same way to strengthen upward, traveling, or growing movement.

<a id="form-pattern-59-1"></a>

![Two-way reversal — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-1.svg)

##### Two-way reversal

Alternate upright and inverted units to create a rhythm of opposing vertical directions.

<a id="form-pattern-59-2"></a>

![Four-way alternation — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-2.svg)

##### Four-way alternation

Cycle units through four orientations so the pattern has no single dominant reading direction.

<a id="form-pattern-59-3"></a>

![Multidirectional rotation — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-3.svg)

##### Multidirectional rotation

Distribute units at many angles to avoid orderly lines and support viewing from every direction.

<a id="form-pattern-59-4"></a>

![Tangential circulation — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-4.svg)

##### Tangential circulation

Turn each unit along a circular tangent like fish or leaves circulating around a center.

<a id="form-pattern-59-5"></a>

![Inward convergence — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-59-5.svg)

##### Inward convergence

Aim units toward one center, or reverse them outward, to create convergence or expansion.

<a id="pattern-panel-word-g60-pattern"></a>

<a id="pattern-group-word-g60-pattern"></a>

#### Motif sequences and beats

Compare motif sequences through alternation, cycles, main-and-filler beats, pairs, clusters, size changes, mixed scales, and even spacing.

<a id="form-pattern-60-0"></a>

![AB alternation — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-0.svg)

##### AB alternation

Alternate two unit types in an ABAB order, using shape or color differences to establish rhythm.

<a id="form-pattern-60-1"></a>

![ABC cycle — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-1.svg)

##### ABC cycle

Cycle three or more unit types in a fixed order to create a longer repeating beat.

<a id="form-pattern-60-2"></a>

![Main-and-filler beat — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-2.svg)

##### Main-and-filler beat

Repeat a large main unit with smaller filler elements so the pattern retains a clear hierarchy.

<a id="form-pattern-60-3"></a>

![Paired motifs — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-3.svg)

##### Paired motifs

Pair two matching or related units first, then repeat the pair instead of isolated single elements.

<a id="form-pattern-60-4"></a>

![Clustered motifs — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-4.svg)

##### Clustered motifs

Assemble small elements into bouquets, fruit clusters, or object groups before repeating each cluster.

<a id="form-pattern-60-5"></a>

![Alternating sizes — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-5.svg)

##### Alternating sizes

Alternate large and small units so scale difference, rather than shape difference, creates the beat.

<a id="form-pattern-60-6"></a>

![Mixed scales — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-6.svg)

##### Mixed scales

Mix several sizes of the same element to suggest depth and increase visual richness.

<a id="form-pattern-60-7"></a>

![Even spacing — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-60-7.svg)

##### Even spacing

Treat consistent open intervals as part of the rhythm, keeping every unit clearly independent.

<a id="pattern-panel-word-g61-pattern"></a>

<a id="pattern-group-word-g61-pattern"></a>

#### Density and gradients

Compare spatial gradients produced by changing motif density, scale, direction, color, or the concentration of surrounding space.

<a id="form-pattern-61-0"></a>

![Sparse open spacing — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-0.svg)

##### Sparse open spacing

Leave generous gaps between a few units for a light, quiet pattern across the full area.

<a id="form-pattern-61-1"></a>

![Dense coverage — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-1.svg)

##### Dense coverage

Pack elements closely, allowing local overlaps so the ground color becomes secondary.

<a id="form-pattern-61-2"></a>

![Density gradient — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-2.svg)

##### Density gradient

Change the number of elements per area gradually to move from sparse to dense or back again.

<a id="form-pattern-61-3"></a>

![Scale gradient — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-3.svg)

##### Scale gradient

Increase or decrease unit size along one direction to suggest advance, distance, or dispersal.

<a id="form-pattern-61-4"></a>

![Orientation gradient — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-4.svg)

##### Orientation gradient

Change each unit’s rotation progressively to create a turning, twisting, or flow-field effect.

<a id="form-pattern-61-5"></a>

![Color gradient — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-5.svg)

##### Color gradient

Keep the layout stable while grading unit color, value, or saturation through a transition.

<a id="form-pattern-61-6"></a>

![Local density contrast — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-61-6.svg)

##### Local density contrast

Place a dense concentration beside a quiet open zone to create a clear visual center of gravity.

<a id="pattern-group-word-g62-pattern"></a>

#### Scatter and controlled randomness

Compare scatter systems by how randomness is constrained through balance, zones, clusters, paths, overlaps, and deliberately reserved clear space.

<a id="form-pattern-62-0"></a>

![Balanced scatter — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-0.svg)

##### Balanced scatter

Avoid visible rows while controlling spacing and visual weight so the overall scatter remains balanced.

<a id="form-pattern-62-1"></a>

![Controlled randomness — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-1.svg)

##### Controlled randomness

Randomize placement only after limiting angle, scale, minimum spacing, and element proportions.

<a id="form-pattern-62-2"></a>

![Zonal scatter — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-2.svg)

##### Zonal scatter

Give different regions distinct elements or densities, with readable zones and naturally softened edges.

<a id="form-pattern-62-3"></a>

![Grouped scatter — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-3.svg)

##### Grouped scatter

Gather elements into local groups, then scatter those clusters across the field instead of spacing everything evenly.

<a id="form-pattern-62-4"></a>

![Path-based scatter — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-4.svg)

##### Path-based scatter

Scatter elements along an invisible arc, wave, or route so the field carries directional flow.

<a id="form-pattern-62-5"></a>

![Overlapping scatter — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-5.svg)

##### Overlapping scatter

Allow scattered elements to overlap, using occlusion to create depth and a sense of accumulation.

<a id="form-pattern-62-6"></a>

![Reserved clear space — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-62-6.svg)

##### Reserved clear space

Keep elements away from wording, subjects, or selected silhouettes so reserved space shapes the pattern.

<a id="pattern-panel-word-g68-pattern"></a>

<a id="pattern-group-word-g68-pattern"></a>

#### Pattern element combinations

Compare how recognizable thematic motifs are mixed, bundled, scattered, linked, or grown into coherent decorative arrangements.

<a id="form-pattern-68-0"></a>

![Thematic object mix — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-0.svg)

##### Thematic object mix

Combine several objects from one theme, such as baking or travel tools, then scatter the complete set.

<a id="form-pattern-68-1"></a>

![Scattered bouquets — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-1.svg)

##### Scattered bouquets

Assemble flowers and leaves into complete bouquets before repeating or scattering each bouquet.

<a id="form-pattern-68-2"></a>

![Scattered flowering branches — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-2.svg)

##### Scattered flowering branches

Preserve the natural connection of local stems, leaves, and blooms in separately scattered sprigs.

<a id="form-pattern-68-3"></a>

![Growing vines — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-3.svg)

##### Growing vines

Fill the field with a branching, turning vine framework and grow small flowers along it.

<a id="form-pattern-68-4"></a>

![Landscape vignettes — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-4.svg)

##### Landscape vignettes

Build miniature scenes from architecture, landscape, and trees, then distribute them in varied directions.

<a id="form-pattern-68-5"></a>

![Narrative fragments — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-5.svg)

##### Narrative fragments

Repeat small scenes of people, animals, or daily activity so each unit carries a miniature story.

<a id="form-pattern-68-6"></a>

![Text-image mix — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-6.svg)

##### Text-image mix

Mix words, letters, numbers, and figures, using size, direction, and spacing to establish rhythm.

<a id="form-pattern-68-7"></a>

![Badge groups — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-68-7.svg)

##### Badge groups

Treat badges, labels, seals, or signs as complete units in a collectible-sticker pattern.

#### Line and dot fields

Compare continuous fields formed by parallel lines, contours, halftone dots, grains, cloud-like patches, or fluid swirls.

<a id="form-pattern-69-0"></a>

![Parallel line field — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-0.svg)

##### Parallel line field

Fill the field with many parallel lines, using line width and fixed or changing gaps for rhythm.

<a id="form-pattern-69-1"></a>

![Contour curves — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-1.svg)

##### Contour curves

Offset multiple curves from one another like contours, growth rings, or topographic lines.

<a id="form-pattern-69-2"></a>

![Dot halftone field — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-2.svg)

##### Dot halftone field

Use dot size, density, and arrangement to create value, shape, or regular texture.

<a id="form-pattern-69-3"></a>

![Granular field — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-3.svg)

##### Granular field

Cover the field with fine grains, short strokes, or fibers whose repetition remains subtle.

<a id="form-pattern-69-4"></a>

![Cloud-like patches — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-4.svg)

##### Cloud-like patches

Fit irregular color patches or soft contours together into a cloudy, mottled full-field surface.

<a id="form-pattern-69-5"></a>

![Fluid swirls — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-69-5.svg)

##### Fluid swirls

Bend and curl curves or color bands along a flow field to suggest vortices or liquid movement.

#### Geometric and textile motifs

Compare established geometric and textile motifs by their unit shape, directional repeat, weave association, and characteristic visual rhythm.

<a id="form-pattern-72-0"></a>

![Polka dots — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-72-0.svg)

<a id="form-pattern-72-2"></a>

![Houndstooth — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/pattern-72-2.svg)

Decorate curved teardrop or comma-shaped motifs internally, then scatter or interlace them.
