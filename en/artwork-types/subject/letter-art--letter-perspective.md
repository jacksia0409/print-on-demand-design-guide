# Angled perspective type

Lettering changes apparent scale across its width to suggest depth.

<a id="understand"></a>

![Angled perspective type: Lettering changes apparent scale across its width to suggest depth.](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/legacy-letter-art--letter-perspective-1.svg)

Composition illustration

HOW TO RECOGNIZE IT

## What defines this direction

Rotation or a uniform shear alone is not necessarily perspective. Show a change in relative scale while retaining recognizable wording.

AI DIRECTIONS

## Take this direction into AI

Use with an image, or ask AI to rewrite your image prompt in this direction.

**Target direction**

Subject-led → Text and subject relationships → Lettering treatments → Angled perspective type

**Input and output**

If given an image, adapt the image to this direction. If given a prompt, rewrite it as a complete prompt ready for image generation.

**Target structure**

Apply a consistent perspective treatment so letter heights, spacing or edges contract with apparent distance. Coordinate that contraction with the direction of the text in the composition.

**Background**

Reference existing background content, treatment and palette, adapting it to the target structure. If absent or only plain or transparent, create theme-related background treatment. An explicit solid, transparent or other background requirement takes precedence.

**Wording**

Keep clearly readable source wording and its language, adapting its presentation. Do not claim to have recovered unreadable text. If no words are supplied, create concise theme-related copy and make the lettering the focus of this treatment. Retain reading order and meaning and check spelling. If an explicit no-text request conflicts with this text-based direction, state the conflict rather than silently adding words.

**Preserve and adapt**

Keep the core theme and identifying features. Use the source treatment and palette as a starting point, changing them only as required by the selected direction. Do not describe newly created content as present in the source. State a conflict between explicit input restrictions and necessary target conditions rather than claiming both were met.

**Scope and boundaries**

Rotation or a uniform shear alone is not necessarily perspective. Show a change in relative scale while retaining recognizable wording.
