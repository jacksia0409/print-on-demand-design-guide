# Textured background

Single subject: Paper grain, particles or another surface character support the foreground content.

<a id="understand"></a>

![Textured background: Single subject: Paper grain, particles or another surface character support the foreground content.](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/legacy-background--single--texture-1.svg)

Composition illustration

HOW TO RECOGNIZE IT

## What defines this direction

A textured backing should not automatically become an independent object or a whole narrative scene. In the texture category, distinguish the main surface fragment from its supporting ground.

AI DIRECTIONS

## Take this direction into AI

Use with an image, or ask AI to rewrite your image prompt in this direction.

**Target direction**

Subject-led → Single subject → Background → Textured background

**Input and output**

If given an image, adapt the image to this direction. If given a prompt, rewrite it as a complete prompt ready for image generation.

**Target structure**

Retain one coherent focal subject. If several independent objects are present, choose the lead subject or organize a clearly unified visual whole.

**Background**

Reference existing surface detail, palette and density, or create a theme-related low-interference texture when absent. Coordinate scale and contrast so the material stays in a supporting role.

**Wording**

Keep clearly readable source wording and its language, adapting its presentation. Do not claim to have recovered unreadable text. If no words are supplied, create a brief related phrase as supporting copy without obscuring key subjects, action or structure. Follow the target hierarchy for existing wording and respect an explicit request for no text.

**Preserve and adapt**

Keep the core theme and identifying features. Use the source treatment and palette as a starting point, changing them only as required by the selected direction. Do not describe newly created content as present in the source. State a conflict between explicit input restrictions and necessary target conditions rather than claiming both were met.

**Scope and boundaries**

A textured backing should not automatically become an independent object or a whole narrative scene. In the texture category, distinguish the main surface fragment from its supporting ground.
