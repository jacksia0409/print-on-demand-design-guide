Compare stone and mineral surfaces by vein, grain, strata, cleavage, crystal, speckle, translucency, and polished or weathered structure.

<a id="form-exp-13-0-0"></a>

<a id="form-exp-13-0-1"></a>

![Granite grains — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-1.svg)

Build the surface from mineral grains that vary in size and color.

![Sandstone strata — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-2.svg)

Form parallel or curving sedimentary bands from fine grains and deposited color layers.

<a id="form-exp-13-0-3"></a>

![Slate layers — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-3.svg)

![Limestone pores — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-4.svg)

##### Limestone pores

Combine fine pores, shallow grooves, and uneven deposits into a limestone surface.

<a id="form-exp-13-0-5"></a>

![Pebble mosaic — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-5.svg)

Fit rounded stones against one another, making both the blocks and joints visible.

![Crystal clusters — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-6.svg)

Cluster many faceted crystals to create a rhythm of sharp points and reflections.

<a id="form-exp-13-0-7"></a>

![Agate bands — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-7.svg)

Wrap the interior with successive curved bands of mineral color.

<a id="form-exp-13-0-8"></a>

![Rock fractures — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-8.svg)

Construct a rough rock surface from sharp facets and broken edges.

<a id="form-exp-13-0-9"></a>

![Folded rock strata — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-9.svg)

![Mineral crust — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-0-10.svg)

#### Earth and sand

Compare earth and sand surfaces through particle size, wind or water patterning, cracks, deposits, compaction, and rough ground relief.

<a id="form-exp-13-1-0"></a>

![Fine sand — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-0.svg)

Combine stones, fine sand, and several grain sizes in one mixed gravel surface.

<a id="form-exp-13-1-6"></a>

![Wind-eroded grooves — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-6.svg)

<a id="form-exp-13-1-7"></a>

![Water-eroded channels — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-7.svg)

<a id="form-exp-13-1-8"></a>

![Moss cover — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-8.svg)

Build a soft, dense granular layer from many tiny moss plants.

![Lichen patches — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-9.svg)

![Volcanic ash — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-1-10.svg)

![Ice cracks — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-13-2-7.svg)

AI DIRECTIONS

## Take this direction into AI

Use with an image, or ask AI to rewrite your image prompt in this direction.

**Target direction**

Textures

**Input and output**

If given an image, adapt the image to this direction. If given a prompt, rewrite it as a complete prompt ready for image generation.

**Target structure**

Translate relevant palette, material and atmosphere into surface-led artwork. Use full coverage, local fragments or layers, reducing unrelated objects that would become independent focal subjects.

**Background**

Reference material, palette and atmosphere, creating relevant surface treatment when missing. A local patch can have a separate backing; a full-area texture merges with its ground. Avoid adding a dominant object or narrative setting.

**Wording**

Keep clearly readable source wording and its language, adapting its presentation. Do not claim to have recovered unreadable text. If no words are supplied, create a brief related phrase as supporting copy without obscuring key subjects, action or structure. Follow the target hierarchy for existing wording and respect an explicit request for no text.

**Preserve and adapt**

Retain relevant material, surface, palette and atmosphere without requiring an object silhouette or complete scene. Create the requested effect when material cues are absent, without claiming to have identified the source’s real material. Do not describe newly created content as present in the source. State a conflict between explicit input restrictions and necessary target conditions rather than claiming both were met.

**Scope and boundaries**

An object silhouette or a whole environment may instead be subject or scene artwork. Not every image without a clear object is a texture.

Code-drawn studies compare composition and visual treatments; media and style examples are conceptual. These directions have not been individually tested with image models. Check generated text, transparency and repeat edges.
