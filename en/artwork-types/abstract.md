# Abstract artwork

Shapes, marks, lines and color relationships lead without a definite object reference.

<a id="abstract-design"></a>

## Abstract composition and treatments

### Abstract elements

<a id="abstract-panel-word-12-0"></a>

<a id="abstract-group-word-12-0"></a>

#### Dots and lines

Compare abstract point and line systems by isolation, clustering, direction, continuity, field density, convergence, and calligraphic energy.

<a id="form-exp-12-0-0"></a>

![Isolated dots — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-0.svg)

##### Isolated dots

Create the composition from a few separate dots whose positions establish their relationship.

<a id="form-exp-12-0-1"></a>

![Clustered dots — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-1.svg)

##### Clustered dots

Use the gathering and dispersal of dots to establish areas of visual emphasis.

<a id="form-exp-12-0-2"></a>

![Dot field — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-2.svg)

##### Dot field

Spread dots at regular intervals until they read as a continuous field.

<a id="form-exp-12-0-3"></a>

![Particle cloud — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-3.svg)

##### Particle cloud

Build cloudlike changes in concentration from a large number of tiny dots.

<a id="form-exp-12-0-4"></a>

![Parallel lines — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-4.svg)

##### Parallel lines

Create rhythm from parallel straight lines by varying their spacing and length.

<a id="form-exp-12-0-5"></a>

![Crossing line web — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-5.svg)

##### Crossing line web

Cross several sets of straight lines to form a visible nonfigurative structure.

<a id="form-exp-12-0-6"></a>

![Zigzags — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-6.svg)

##### Zigzags

Use sharply turning line segments to create an angular rhythm.

<a id="form-exp-12-0-7"></a>

![Arcs — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-7.svg)

##### Arcs

Combine lines with different curvatures into a soft formal relationship.

<a id="form-exp-12-0-8"></a>

![Continuous curves — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-8.svg)

##### Continuous curves

Run one or several uninterrupted curves across the entire field.

<a id="form-exp-12-0-9"></a>

![Broken lines — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-9.svg)

##### Broken lines

Create a beat through the interruption and resumption of line segments.

<a id="form-exp-12-0-10"></a>

![Converging line bundles — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-10.svg)

##### Converging line bundles

Converge several lines toward one or more focal points.

<a id="form-exp-12-0-11"></a>

![Flowing line field — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-11.svg)

##### Flowing line field

Arrange many curves like a wind field or directional current.

<a id="form-exp-12-0-12"></a>

![Contour-line field — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-12.svg)

##### Contour-line field

Use nested curves to express undulation and successive levels.

<a id="form-exp-12-0-14"></a>

![Writing-like lines — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-14.svg)

##### Writing-like lines

Preserve the speed and gesture of handwriting without forming text that must be read.

<a id="form-exp-12-0-15"></a>

![Variable-width lines — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-0-15.svg)

##### Variable-width lines

Change line width continuously to suggest force or spatial depth.

#### Geometry and modules

Compare abstract geometry through shape family, modular construction, grid logic, tiling, fragmentation, and hard-edged spatial relationships.

<a id="form-exp-12-1-0"></a>

![Circles and arcs — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-1-0.svg)

##### Circles and arcs

Make circles, semicircles, and arcs the principal formal relationships.

<a id="form-exp-12-1-1"></a>

![Squares and rectangles — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-1-1.svg)

##### Squares and rectangles

Compose right-angled blocks through deliberate differences in scale and position.

<a id="form-exp-12-1-2"></a>

![Triangles and sharp angles — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-1-2.svg)

##### Triangles and sharp angles

Use triangles and pointed directions to generate visual tension.

<a id="form-exp-12-1-3"></a>

![Polygon assembly — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-1-3.svg)

##### Polygon assembly

Join or overlap neighboring polygons until they read as one whole.

<a id="form-exp-12-1-4"></a>

![Color strips — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-1-4.svg)

##### Color strips

Organize elongated color blocks through changes in width, direction, and spacing.

<a id="form-exp-12-1-5"></a>

![Grid composition — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-1-5.svg)

##### Grid composition

Let a horizontal and vertical grid become the primary structure of the image.

<a id="form-exp-12-1-6"></a>

![Modular assembly — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-1-6.svg)

##### Modular assembly

Combine standard modules according to a limited set of rules.

<a id="form-exp-12-1-7"></a>

![Geometric tessellation — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-1-7.svg)

##### Geometric tessellation

Fit shapes directly against one another to create a continuous plane of modules.

<a id="form-exp-12-1-8"></a>

![Hard-edge geometry — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-1-8.svg)

##### Hard-edge geometry

Keep shape boundaries crisp, without soft transitions between neighboring colors.

<a id="form-exp-12-1-9"></a>

![Outlined geometry — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-1-9.svg)

##### Outlined geometry

Define shapes only with outlines while leaving their interiors open.

<a id="form-exp-12-1-10"></a>

![Irregular geometry — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-1-10.svg)

##### Irregular geometry

Distort geometric forms slightly while retaining both structure and a handmade character.

<a id="form-exp-12-1-11"></a>

![Geometric slices — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-1-11.svg)

##### Geometric slices

Slice planes apart, offset their pieces, and recombine them into a new arrangement.

#### Organic and fluid forms

Compare organic abstract forms through growth, flow, cells, foam, clouds, melting, waves, and other nongeometric deformation.

<a id="form-exp-12-2-0"></a>

![Free organic blocks — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-2-0.svg)

##### Free organic blocks

Build flat relationships from irregular shapes with softly rounded edges.

<a id="form-exp-12-2-1"></a>

![Biomorphic forms — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-2-1.svg)

##### Biomorphic forms

Compose the field from forms resembling cells or biological structures without depicting organisms.

<a id="form-exp-12-2-2"></a>

![Liquid flow — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-2-2.svg)

##### Liquid flow

Use fluid shapes to express direction and changes in apparent viscosity.

<a id="form-exp-12-2-3"></a>

![Swirling flow — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-2-3.svg)

##### Swirling flow

Coil forms inward toward or outward from a center of rotation.

<a id="form-exp-12-2-4"></a>

![Oscillating ripples — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-2-4.svg)

##### Oscillating ripples

Create continuous visual movement through periodic rises and falls.

<a id="form-exp-12-2-5"></a>

![Cloud-like masses — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-2-5.svg)

##### Cloud-like masses

Gather, separate, and interweave masses whose boundaries remain soft.

<a id="form-exp-12-2-6"></a>

![Branching growth — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-2-6.svg)

##### Branching growth

Grow forms outward according to a consistent branching rule.

<a id="form-exp-12-2-7"></a>

![Root-like networks — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-2-7.svg)

##### Root-like networks

Connect fine branches into an irregular rootlike network.

<a id="form-exp-12-2-8"></a>

![Cell partitions — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-2-8.svg)

##### Cell partitions

Divide the field into adjoining regions with flexible organic boundaries.

<a id="form-exp-12-2-9"></a>

![Foam clusters — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-2-9.svg)

##### Foam clusters

Compress circular bubbles of different sizes into layered foamlike clusters.

<a id="form-exp-12-2-10"></a>

![Melting stretch — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-2-10.svg)

##### Melting stretch

Stretch or drip forms as though the material were melting.

<a id="form-exp-12-2-11"></a>

![Folds and pleats — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-2-11.svg)

##### Folds and pleats

Create a rhythm of ridges and valleys from bent ribbonlike planes.

#### Marks and gestures

Compare gestural mark families by brush load, speed, pressure, wetness, repetition, splatter, scraping, and visible bodily action.

<a id="form-exp-12-3-0"></a>

![Broad brush sweeps — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-3-0.svg)

##### Broad brush sweeps

Build the image through the direction and coverage of broad brush sweeps.

<a id="form-exp-12-3-1"></a>

![Dry-brush gaps — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-3-1.svg)

##### Dry-brush gaps

Leave missing paint and exposed ground visible as evidence of bristles and speed.

<a id="form-exp-12-3-2"></a>

![Wet diffusion — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-3-2.svg)

##### Wet diffusion

Let pigment spread into wet areas and settle into soft edges.

<a id="form-exp-12-3-3"></a>

![Splashes — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-3-3.svg)

##### Splashes

Use droplets and outward spray marks to create an irregular rhythm.

<a id="form-exp-12-3-4"></a>

![Drip trails — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-3-4.svg)

##### Drip trails

Allow pigment to leave trails along gravity or a tilted direction.

<a id="form-exp-12-3-5"></a>

![Scraped marks — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-3-5.svg)

##### Scraped marks

Form broken lines by scraping away or dragging through applied material.

<a id="form-exp-12-3-6"></a>

![Overpainting — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-3-6.svg)

##### Overpainting

Cover color layers repeatedly while retaining visible traces of hand-made revision.

<a id="form-exp-12-3-7"></a>

![Short-stroke buildup — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-3-7.svg)

##### Short-stroke buildup

Accumulate many short strokes whose density and direction change across the field.

<a id="form-exp-12-3-8"></a>

![Writing gestures — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-3-8.svg)

##### Writing gestures

Use quick writing-like gestures to establish an abstract rhythm.

<a id="form-exp-12-3-9"></a>

![Circular smears — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-3-9.svg)

##### Circular smears

Leave continuous curves and overlaps through repeated circular smearing motions.

<a id="form-exp-12-3-10"></a>

![Pressed marks — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-3-10.svg)

##### Pressed marks

Repeat pressed marks that remain related but never exactly identical.

<a id="form-exp-12-3-11"></a>

![Erased negative space — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-3-11.svg)

##### Erased negative space

Create active negative shapes by removing or simulating the erasure of material.

Compare abstract figure-ground construction through adjacency, opaque or transparent overlap, shared boundaries, masking, cutting, and reversals.

<a id="form-exp-12-5-0"></a>

![Adjacent assembly — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-5-0.svg)

##### Adjacent assembly

Place shapes against shared boundaries without allowing them to overlap.

<a id="form-exp-12-5-1"></a>

![Opaque overlap — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-5-1.svg)

##### Opaque overlap

Build layers by letting opaque planes visibly obscure one another.

<a id="form-exp-12-5-2"></a>

![Transparent overlap — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-5-2.svg)

##### Transparent overlap

Keep both colors and contours visible within the region where translucent shapes overlap.

<a id="form-exp-12-5-3"></a>

![Intersection only — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-5-3.svg)

##### Intersection only

Retain only the area shared by the intersecting shapes.

<a id="form-exp-12-5-4"></a>

![Subtractive cutout — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-5-4.svg)

##### Subtractive cutout

Remove the form of one shape from inside another.

<a id="form-exp-12-5-5"></a>

![Shared boundary — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-5-5.svg)

##### Shared boundary

Use a single contour to define two neighboring regions at the same time.

<a id="form-exp-12-5-6"></a>

![Positive-negative exchange — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-5-6.svg)

##### Positive-negative exchange

Give the solid forms and the surrounding empty areas equal visual importance.

<a id="form-exp-12-5-7"></a>

![Figure-ground reversal — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-5-7.svg)

##### Figure-ground reversal

Make attention switch between shapes read as foreground and shapes read as background.

<a id="form-exp-12-5-8"></a>

![Nested window — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-5-8.svg)

##### Nested window

Open a window within one shape to reveal another layer of abstract content.

<a id="form-exp-12-5-9"></a>

![Nested shapes — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-5-9.svg)

##### Nested shapes

Nest shapes successively to create progression in scale or apparent depth.

Let selected forms break through the grid or boundary that originally contained them.

Cut a shape into pieces, then move or rotate the separated fragments.

#### Order and generation

Compare generated order through repetition, symmetry, glide, recursion, fractal growth, randomness, noise, parameter change, topology, and glitch rearrangement.

<a id="form-exp-12-6-0"></a>

![Repeated module — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-6-0.svg)

##### Repeated module

Repeat the same shape several times according to one consistent rule.

<a id="form-exp-12-6-1"></a>

![Rotational array — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-6-1.svg)

##### Rotational array

Rotate successive units around a shared center in an ordered array.

<a id="form-exp-12-6-2"></a>

![Mirror symmetry — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-6-2.svg)

##### Mirror symmetry

Correspond forms across one or several axes of reflection.

<a id="form-exp-12-6-3"></a>

![Glide arrangement — visual study](https://images.podplo.app/official/pod-guide/diagrams/b2382e28cd57b514819e/exp-12-6-3.svg)

## Take this direction into AI

Use with an image, or ask AI to rewrite your image prompt in this direction.

**Target direction**

Abstract artwork

**Input and output**

If given an image, adapt the image to this direction. If given a prompt, rewrite it as a complete prompt ready for image generation.

**Target structure**

Translate palette, rhythm, direction or mood into geometric forms, organic flow, marks or color fields. Reorganize relationships and space rather than preserving a concrete object as the main goal.

**Background**

Reference background colors, rhythm and mood. If absent, create related supporting ground or spatial relationships. Figurative source surroundings may be simplified into supporting cues without replacing the nonfigurative composition.

**Wording**

Keep clearly readable source wording and its language, adapting its presentation. Do not claim to have recovered unreadable text. If no words are supplied, create a brief related phrase as supporting copy without obscuring key subjects, action or structure. Follow the target hierarchy for existing wording and respect an explicit request for no text.

**Preserve and adapt**

Retain theme, atmosphere, palette, rhythm or direction while allowing concrete object identity to be reduced or removed. Do not simultaneously require the original object silhouette to remain intact. Do not describe newly created content as present in the source. State a conflict between explicit input restrictions and necessary target conditions rather than claiming both were met.

**Scope and boundaries**

An identifiable stylized object remains a subject treatment. Material surface character belongs under textures when it is the main expression.

Code-drawn studies compare composition and visual treatments; media and style examples are conceptual. These directions have not been individually tested with image models. Check generated text, transparency and repeat edges.
