# Personality and fun

Create personal designs from nicknames, inside jokes, hobbies, roles, and group traditions.

## Design around an inside joke

A nickname or shared joke can anchor a compact, highly personal design.

A nickname, catchphrase, or shared joke can lead a compact design that makes sense to the intended group. Use the familiar phrase without including private details that should stay private.

## Build a coordinated group set

4PC and [6PC Grid Generator](https://podplo.app/skills/six-piece-grid) turn one shared motif into a coordinated set with distinct variations.

Use one shared motif for a team, club, or community, then vary the name, role, color, or number for each member. 4PC and [6PC Grid Generator](https://podplo.app/skills/six-piece-grid) keep the set coordinated without making every design identical.
