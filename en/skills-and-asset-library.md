## Turn a pet photo into a royal portrait

[Royal Pet Portrait](https://podplo.app/skills/royal-pet-portrait) adds period costume and scenery while keeping the pet recognizable.

[Royal Pet Portrait](https://podplo.app/skills/royal-pet-portrait) turns a familiar pet photo into a regal character portrait. The costume and setting can change dramatically while the face shape, coat markings, and expression keep the pet unmistakably itself.

## Tag assets for easy reuse

Clear tags make it easy to find an asset and create a seasonal variation with [Make It Christmas](https://podplo.app/skills/make-it-christmas).

Tags for subject, season, layout, color, and source make useful assets easy to find again. For example, a pet portrait tagged for Christmas is ready for a [Make It Christmas](https://podplo.app/skills/make-it-christmas) variation that still features the same pet.

## Reuse a layout with new content

[Dinosaur Name Pattern](https://podplo.app/skills/dinosaur-name-pattern) adapts one proven repeat layout to each new name.

A strong composition can support a new name, subject, or color without feeling copied. [Dinosaur Name Pattern](https://podplo.app/skills/dinosaur-name-pattern) keeps the playful repeat structure while adjusting the spacing for each name.
