# Make it personal with a name or message

Add a name, a few meaningful words, or a special date. Make the text part of the design.

[Floral Name Frame](https://podplo.app/skills/floral-name-frame) places a name such as ANDREA inside a balanced watercolor floral frame. The spacing adjusts to the name, making the same floral concept feel custom each time.
