# Turn one idea into a collection

Create a coordinated four- or six-piece set with a different design in each panel. Eight-piece examples are pending.

<a id="four-piece-series"></a>

## 4PC: explore four directions

[4PC Grid Generator](https://podplo.app/skills/four-piece-grid) develops one reference into four coordinated design directions.

[4PC Grid Generator](https://podplo.app/skills/four-piece-grid) develops one reference into four related but distinct compositions. The subject stays consistent while the layout, supporting elements, and focal point change from panel to panel.
